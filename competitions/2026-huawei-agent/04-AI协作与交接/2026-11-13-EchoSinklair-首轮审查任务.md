# TEAM-REVIEW-01：Agent 安全与稳定性审查

日期：2026-11-13。负责人：EchoSinklair。队长已明确首轮审查方向；任务启动仍等待可获取的共同基线完整 SHA。本文不是模型接入、产品修复或远端操作授权。

## 为什么做与先读什么

先理解 Agent 如何拿到环境、注册工具、等待审批、执行和归还结果，找出影响安全与稳定性的真实断点，再决定后续 Agent 和端侧模型优化。阅读顺序见 [组员入门](../../../docs/development/team-onboarding.md)，规则见 [固定流程](../../../docs/development/team-workflow.md)和 [AGENTS](../../../AGENTS.md)。

## 审查范围与起点

| 主题 | 源码起点 | 重点检查 |
|---|---|---|
| 目标与事件身份 | [前端 adapter](../../../src/modules/ai/lib/sidecar-adapter.ts)、[AI 状态](../../../src/modules/ai/store/) | 切换对话/终端、取消、重连和迟到事件是否串入另一任务 |
| Agent 生命周期 | [门面](../../../src-tauri/sidecar/agent_facade.py)、[Strands 实现](../../../src-tauri/sidecar/strands_backend/) | 注册与 schema、审批等待、真正取消、超时与重试是否有重复主人 |
| 风险与授权 | [工具及注册](../../../src-tauri/sidecar/strands_backend/tools/)、[风险实现](../../../src-tauri/sidecar/tools/risk.py)、[风险配置](../../../src-tauri/sidecar/config/risk_rules.yaml) | 风险判断是否覆盖完整执行语义；观察/确认/自动模式与实际执行边界一致 |
| 输入/输出与证据 | [终端模块](../../../src/modules/terminal/)、[运行日志实现](../../../src-tauri/sidecar/strands_backend/agent_log.py) | 回显归属、未知状态、已执行写操作不重放、内容截断与脱敏 |
| 不可信资料与后续模型 | [输入与建议边界](../../../docs/plans/terminal-prediction/2026-11-13-v1.0-输入与建议边界.md)、[实验目录](../../../experiments/) | 工具/知识内容是否越权成指令；模型建议是否只能显式生成并在接受时重验目标 |

范围是沿当前生产入口审查，不要求无差别扫完仓库。已有风险/异步/输入边界候选尚未全验收；若基线未包含本地候选，如实标记“版本不同，无法核该候选”，不得当成缺陷已经修复。

## 本轮可以交付什么

- 自己的分支：`docs/2026-11-13-echosinklair-agent-review`。开始日不同则更新日期；后续复现测试另用明确的 `test/` 任务分支。
- 审查摘要：`docs/updates/YYYY-MM-DD-TEAM-REVIEW-01-Agent审查摘要.md`，与本任务 PR 同交。每条记录基线/HEAD、文件行号、预期/实际、状态、影响、证据、建议和未测部分。
- 必要时在现有测试目录补最小、无网络、合成数据的反例；先给队长确认测试文件清单，不修改产品、依赖、既有安全策略或删改失败断言。
- 可公开摘要之外的漏洞细节，遵循 [安全政策](../../../SECURITY.md)私下交队长；原始证据不放公开 Fork/PR。

发现分为“可复现缺陷／源码可证明／待验证推测／环境或依赖阻断／本次未覆盖”。优先级按实际影响判定；不以发现数量评价工作，不为了填表编造漏洞。每个主题记录已查入口和边界，没发现也如实说明范围。

## 验收与权限

正常允许路径与对应拒绝/取消/切换/迟到路径都要说明；只证明一个函数存在或模拟 registry 永远通过不算证据。记录实际命令、解释器、退出码、所测提交；源码检查、离线测试、真实桌面、SSH、模型分别标记。

本轮不调用真实付费模型、不读队长凭据、不连真实服务器、不跑未经审查的安装/下载脚本、不改共享环境、不推主库或合并。完成摘要后在自己的 Fork 提 PR 等待队长与 ROOT；具体复现环境另由队长批准。
