# TEAM-REVIEW-02：连接、文件与知识链路审查

日期：2026-11-13。负责人：Yan-0914。队长已明确首轮审查方向；任务启动仍等待可获取的共同基线完整 SHA。先审安全性和稳定性，确认后再拆知识、运维技能与连接界面改进任务。

## 为什么做与先读什么

从运维用户的完整路径检查“连接正确目标 → 切目录/用户 → 浏览和编辑文件 → 获取知识/调用技能 → 查看真实结果”，优先发现串会话、数据丢失、凭据暴露与无法恢复的问题。先读 [组员入门](../../../docs/development/team-onboarding.md)、[终端与工作区](../../../docs/architecture/terminal-workspace.md)、[知识与日志](../../../docs/architecture/knowledge-observability.md)及 [AGENTS](../../../AGENTS.md)。

## 审查范围与起点

| 主题 | 源码起点 | 重点检查 |
|---|---|---|
| SSH 连接与身份 | [Rust SSH](../../../src-tauri/src/modules/ssh/)、[连接状态](../../../src/modules/ssh-explorer/)、[工作区](../../../src/modules/spaces/) | 主机指纹、凭据生命周期、失败与取消、断连和重连后的真实目标 |
| 终端和文件跟随 | [终端](../../../src/modules/terminal/)、[资源管理器](../../../src/modules/explorer/) | 多标签独立性、目录跟随、su 后 shell 身份与文件认证身份的区别；不能把嵌套 SSH 当新文件连接 |
| 文件安全与恢复 | [Rust 系统模块](../../../src-tauri/src/modules/)、[App 装配](../../../src/app/App.tsx) | 路径/目标归属、未保存修改、传输取消和错误后的状态；先只读盘点，不实际覆盖用户文件 |
| 知识与导入 | [知识前端](../../../src/modules/ai/components/KnowledgeBrowser.tsx)、[知识后端](../../../src-tauri/sidecar/knowledge/)、[整理脚本](../../../src-tauri/sidecar/scripts/) | 内置/我的/原始参考来源、旧中文是否被覆盖、分页/标题/重复、导入冲突和备份恢复 |
| 运维技能与提示数据 | [技能前端](../../../src/modules/skills/)、[工具实现](../../../src-tauri/sidecar/strands_backend/tools/) | 技能来源/许可、参数、写操作审批、幂等与回滚；知识/技能文本不能直接授予权限 |

同 EchoSinklair 的交叉处按职责拆：你验证连接/文件/内容侧的身份和状态，Echo 验证 Agent 调用/审批侧；共同问题引用同一个发现，不能两人同时改装配文件或各做一套补丁。

## 验收与权限

说明连接成功与失败/取消/断连/切目标的对应场景；文件侧检查只读与拒绝、未保存内容与错误恢复；知识侧检查有数据/空库/缺失/冲突。不能把原始抓取条数当知识质量，也不能用源码/假服务代替真实 SSH 或安装验收。

本轮不连接真实服务器、不共享密码、不改远端 profile 或主机信任记录、不整理/覆盖真实知识库、不调用翻译模型、不跑批量爬虫。若需要测试机，队长另发环境和具体权限；本机旧授权不会自动转给新成员。自己的 Fork PR 提交后等待队长与 ROOT，不自行合并。

## 后续候选方向

1. **知识整理**：先复用已有中文与确认来源，改善命名、去重、摘要和层级；内置/我的/原始参考保留边界，导入先临时库预览、备份和冲突处理，不合并覆盖私人库。翻译任务另定资料许可和预算，不默认批量消耗模型额度。
2. **运维 Skill**：先选少量高频只读诊断任务，逐项给参数、环境、失败场景和回归；写操作的审批、回滚与验证单独评审，不凭技能文本绕过工具策略。
3. **图形化连接**：先盘点现有 SSH 连接管理、文件传输与隧道界面的问题和可复用开源能力。若指 RDP/VNC 远程桌面，需另确认目标和安全架构，不能自动扩成这一轮实现范围。
