# 私密材料：只放不适合进Git的内容

**普通可公开截图已改为放05对应成员目录、随任务分支提交，不要求原件全部私发。private仍不随Fork同步。**

| 路径 | 内容与交付 |
|---|---|
| `成员证据/账号/YYYY-MM-DD/任务编号/` | 含敏感信息的截图原件、未脱敏完整对话/日志；必要时通过已有私密渠道交队长 |
| `身份与报名回执/` | 个人报名/实名认证和平台凭证，队长保管 |
| `导出提交包/版本/` | 大视频、完整ZIP及含联系方式的提交回执，不入公开Git |

① 判断是否敏感 → ② 敏感原件留此 → ③ 需要公开则另存脱敏版到05并关联证据ID → ④ 只有确需队长接收的私密材料才私密交付。

不要收集或传播API密钥、密码、身份证号或隐藏系统提示词。已有原件/备份保留，不为整理而删除；无法安全交付时标待交，不能改传公开Issue。
