# 私密材料：本机保护与向队长交付

**这个目录不会自动跨机器同步。源码Fork、公开PR、Issue附件和聊天公开链接都不能代替私密交付。**

| 路径约定 | 放什么 |
|---|---|
| `成员证据/账号/YYYY-MM-DD/任务编号/` | 本人的原始CodeArts截图/对话、原始测试日志、录屏；按证据ID命名 |
| `身份与报名回执/` | 由队长保管的个人报名/实名认证和平台凭证 |
| `导出提交包/版本/` | 经审核的完整作品zip、原视频和提交回执 |

① 当阶段实际发生时留原件 → ② 另做脱敏副本 → ③ 在公开材料清单只写证据ID/文件名/指纹/状态 → ④ 当天用团队已有私聊渠道私发队长 → ⑤ 队长按同一路径归档并确认已收。

暂没有私密接收渠道时，在任务中报“原件已留存、待私密交付”，继续其它已授权工作；不要为了赶进度上传公开Fork/PR/Issue。若以后用团队网盘，只记录队长确认的受限位置，不在公开说明贴访问口令。

原始与脱敏版分别保留，不能覆盖原图。不要收集或传播API密钥、密码、身份证号、隐藏系统提示词；截图检查账号、浏览器地址、终端路径/主机、通知弹窗与日志。已有备份/原件不得擅自删除。
