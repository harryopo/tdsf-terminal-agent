# 2026 华为智能体创新赛工作目录

本目录按用户提供的 2026-11-13 赛事要求整理。赛事资格、时间、格式与平台状态以组织方最新公告为准；文档整理不等于已经报名或提交作品。

合作开发先读 [新组员入门](../../docs/development/team-onboarding.md)、[三人分工与开发说明](04-AI协作与交接/三人分工与开发说明.md)及[当前协作备赛计划 v1.1](03-方案书/2026-11-13-v1.1-审查优先与成员分工.md)。队长已选 Fork 模式，EchoSinklair 与 Yan-0914 先按专长审安全和稳定性；共同代码基线未发布，首轮尚未开工，组员 PR 不自行合并。

| 目录 | 用途 |
|---|---|
| `01-赛事要求` | 原始要求、来源与核验日期；变动保留版本 |
| `02-调研资料` | 需求、竞品、官方技术核验，与产品事实分开 |
| `03-方案书` | 比赛方案按日期/版本排列，指向当前确认版本 |
| `04-AI协作与交接` | 任务、分工、真实贡献、验收与后续交接 |
| `05-作品材料` | 说明书、PPT 源稿、架构图和成品 |
| `06-验收与演示` | 演示脚本、使用路径和与版本绑定的结果 |
| `07-提交清单` | 最终文件、版本/指纹、平台回执和遗漏检查 |
| `private` | 报名个人资料、原始凭证、未脱敏记录与大型提交包 |

赛事原要求列出的最终包为 `ppt/project/video/codearts_proof/readme` 五类，提交时从工作目录导出，不反向以导出包作为唯一源稿。

本项目已有历史 AI 开发与开源基础；码道使用证明必须来自真实发生的开发，注明任务和工具，不能把其它 AI 的旧工作重新归属。当前尚无因本轮整理新增的赛事工具使用证明或提交结果。
