# 提交清单与导出责任

**队长统一打包/上传，成员交材料不等于批准合并或正式参赛提交。**

① 收齐来源和证明 → ② 核同一代码版本 → ③ 按五目录导出 → ④ 核可运行与隐私/许可 → ⑤ 队长确认 → ⑥ 平台上传并留回执

进入[作品提交模板区](作品提交/README.md)。只创建了目录和说明，不代表五类材料已齐全；最终包不能只包含README。

| 检查 | 状态/负责人 |
|---|---|
| 官方资格、截止、格式和提交频次 | 待队长平台核对 |
| 报名/三人实名认证/既有项目口径 | 待队长确认，原回执private |
| PPT/演示/运行说明/开源说明 | 逐项实填，不预填完成 |
| 真实CodeArts核心工具证明 | 各成员提交原件，队长核真实性及增量 |
| 同一SHA、安装或启动步骤可复现 | ROOT与队长按真实环境验收 |
| 敏感信息、许可、文件完整性与SHA256 | 导出后复核 |
| 上传状态/版本/回执 | 仅实际提交后登记 |

原整理稿的包名为“作品名称+队伍名称+版本号+联系方式”；含联系方式的最终zip与平台回执放private，不作为公开仓库文件名。本轮不自动制作安装包、上传赛事或替团队确认报名。
