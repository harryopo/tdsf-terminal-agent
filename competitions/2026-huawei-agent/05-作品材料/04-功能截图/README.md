# 功能截图清单

| 项目 | 要求 |
|---|---|
| 放什么 | 可公开的截图说明Markdown；原图/脱敏副本放private并用证据ID关联。 |
| 真实性与边界 | 拍摄环境、所测SHA、场景前提和实际结果必须写清。真实运行、合成响应、组件测试分开；先打码再考虑公开，不上传密钥/账号/服务器信息。 |
| 命名 | `YYYY-MM-DD_账号_任务编号_简述.md`；每项关联证据ID与源码SHA |
| 原始材料 | [按private规则留存/私发队长](../../private/README.md)，不要作为公开附件上传 |

① 完成负责阶段 → ② 保留真实原件 → ③ 自查脱敏/来源 → ④ 同一工作包PR交摘要 → ⑤ 队长复核后选入作品包。
