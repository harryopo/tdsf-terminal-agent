# 码道使用证明索引

| 项目 | 要求 |
|---|---|
| 放什么 | 仅真实发生的CodeArts任务索引、时间、成员、工具版本、代码差异和凭证位置。 |
| 真实性与边界 | 原始Prompt/对话/截图进private；本机Codex、其它模型或历史代码按实际工具记录，不冒充CodeArts。目录存在不表示已有证明。 |
| 命名 | `YYYY-MM-DD_账号_任务编号_简述.md`；每项关联证据ID与源码SHA |
| 原始材料 | [按private规则留存/私发队长](../../private/README.md)，不要作为公开附件上传 |
