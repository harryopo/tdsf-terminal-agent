# 项目说明

| 项目 | 要求 |
|---|---|
| 放什么 | Markdown源稿：场景与目标用户、现有能力、使用路径、已知限制、开发增量。 |
| 真实性与边界 | 成员按模块写，队长/ROOT汇总。分清源码实现、自动检查、真实桌面/SSH和安装包验证；不要把长期设想写成比赛成品。 |
| 命名 | `YYYY-MM-DD_账号_任务编号_简述.md`；每项关联证据ID与源码SHA |
| 截图与敏感材料 | 可公开真实截图按[材料规范](../README.md)放04/05成员目录随分支提交；敏感原件才留[private](../../private/README.md) |

① 完成负责阶段 → ② 保留真实原件 → ③ 自查脱敏/来源 → ④ 同一工作包PR交源稿/可公开图和索引 → ⑤ 队长复核后选入作品包。
