# 阶段交付模板（工作包内复用）

① 基线 → ② 本阶段代码/验证 → ③ 证据 → ④ 受阻/下一阶段 → ⑤ 整包是否可提审

| 字段 | 内容 |
|---|---|
| 工作包 / 负责人 / Draft PR | 待填写 |
| 起始SHA / 当前HEAD / 最近同步主线 | 待填写 |
| 完成的用户路径/改动文件 | 待填写 |
| 验证命令、版本、退出码、唯一用例数 | 待填写；重跑不重复累计 |
| 原生截图/码道记录/原始输出的证据ID | 待填写；未运行如实写未测 |
| 失败、环境受阻、旧缺陷与新增缺陷 | 分开填写，保留失败输出 |
| 后续步骤 / 文件冲突 / 待决定 | 只报实质阻断，不为普通小改动反复申请 |
| 是否整包就绪 | 未就绪 / 待队长与ROOT验收；不预填已合并 |

可公开截图直接随分支入05对应成员目录，清单链接到图片和实际源码SHA；敏感原件才留private，不重复私发普通图。

包内的小提交持续推同一Draft PR；当阶段范围、接口、安全策略或真实资源权限变化时先报告；其它实现和复测按已批准范围自行完成。
