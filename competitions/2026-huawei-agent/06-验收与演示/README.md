# 验收与演示

① 对应基线 → ② 跑定向与编译检查 → ③ 记录失败/通过 → ④ 实测用户路径 → ⑤ 留截图/录屏 → ⑥ 整包汇总

| 内容 | 目录 | 要求 |
|---|---|---|
| 可公开测试摘要/覆盖表 | [01-测试记录](01-测试记录/README.md) | 命令、版本、退出码、所测SHA和唯一用例数；保留失败 |
| 演示步骤/讲解/备用路径 | [02-演示脚本](02-演示脚本/README.md) | 只演示实际功能，不用合成结果冒充真实运行 |
| 录屏索引/版本/时长 | [03-演示视频](03-演示视频/README.md) | 原视频私密交队长，审核成品再导出 |

| 验证层级 | 可以证明 | 不可据此宣称 |
|---|---|---|
| 源码审查 | 当前代码路径/合同事实 | 已在真实环境复现 |
| 假IPC/离线回放 | 特定输入下断言成立 | 真实模型/服务器通过 |
| 类型/lint/构建 | 对应提交能检查/编译 | 功能和安全问题已清零 |
| 原生桌面/SSH | 被实际运行的目标与场景 | 所有服务器/安装版本稳定 |
| 安装/升级 | 指定系统和包的实际安装结果 | 未测平台或旧包具有新修复 |

测试原始日志可能含敏感信息，先本机保存，再按[材料规则](../05-作品材料/README.md)分级共享。未授权真实服务器/模型时不要自行连接；环境阻断保持Draft交接，不补造截图或退出码。
