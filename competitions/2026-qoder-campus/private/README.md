# private · 私密比赛材料

本目录用于保存不适合公开 Git 的比赛原件：

- 身份、报名回执、证件与联系方式。
- 未脱敏的完整对话、日志、服务器信息与凭据。
- 调研原始抓取、候选清单与过程 ledger。
- 调试截图、旧模拟版截图和历史失败证据。
- 大视频、压缩包与最终导出包。

规则：

- private 不随公开 Fork 同步；需要跨电脑交付时使用受限私密渠道。
- 不在公开文档中链接 private 原件；只引用脱敏后的公开副本或摘要。
- 不把密码、Token、私钥或完整环境变量写入本目录的说明文件。
- 清理时先核对引用与归属，优先隔离，不直接删除唯一证据。
