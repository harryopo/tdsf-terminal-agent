## 边界

- 队长负责最终合并、提交与对外发布；AI 不代替人类审批或认证。
- 代码、测试与 `docs/updates` 更新说明同 PR；比赛材料按本赛事目录归档。
- 可公开截图按成员/日期/任务命名；敏感原件、完整日志、身份资料和大视频只放 private。
- Qoder Sites 描述文件与部署绑定由工具维护，不手写、不复制到别的目录。
