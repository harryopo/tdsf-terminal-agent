## 2. 逻辑与错误恢复

- [x] 并发 `start()` 复用同一 Promise，只创建一个模拟器。
- [x] 同步构造异常返回可捕获的拒绝 Promise，不绕过页面错误态。
- [x] 启动超时会销毁模拟器并进入可见错误态。
- [x] `destroy()` 有 5 秒超时；destroy-before-start 不卡死，可再次启动。
- [x] `emulator-stopped` 会停止输入；启动前停止不会被迟到的 started 事件反转。
- [x] WASM/BIOS/ISO 资源 HEAD 预检有 10 秒超时；WASM 404 与挂起预检均显示错误和重试入口。
- [x] 输入使用 UTF-8 字节发送，中文/emoji 不被 `charCodeAt` 截断。
- [x] 基线捕获和重置并发调用复用同一 Promise。
- [x] `destroy()` 忽略迟到串口输出。
- [x] 登录输入不会进入学习状态机，不产生假回执。
- [x] 命令回显会从输出证据中剔除；`ls -la` 与 `ls -l /etc/passwd` 的报错文本不再误通过。
- [x] 方向键/Tab/编辑键进入 line-edited 状态；hint 不再拼接未知缓冲。
- [x] 编辑后本地缓冲与真实回显不一致时，以真实 shell 回显为准。
- [x] Enter 前已到达的 shell 回显会保留，不会把首行输出误当命令。
- [x] 逐字节 ANSI 颜色码跨 chunk 拼接时仍能正确提取目录证据。
- [x] 右侧回执清洗零宽/替换字符，空格显示为 `·`，原始命令与 token 保持不变。
- [x] 连续粘贴/快速输入的命令排队逐条结算，出队时绑定当前步骤。
- [x] 根目录提示符 `/% ` 能正常结束命令并解锁切换/重置。
- [x] 后端证据匹配先剔除命令回显与提示符，不会把 `du -sh /root` 的回显当作成功输出。
- [x] 进度上报与清除串行排队；延迟重置期间锁定输入，新进度不会被旧重置删除。
- [x] session 503 时显示“进度仅本机”，不再误报匿名进度已连接。
- [x] 切任务保留真实终端缓冲；命令执行中切任务、hint、重置均被拦住。
- [x] 重复点击 hint 不会拼成 `pwdpwd`。
- [x] 退格、Ctrl+C、清屏按键不会污染命令状态。
