## 命名与公开规则

- 截图命名：`YYYY-MM-DD_账号_任务编号_序号_场景.png`。
- 同一截图只放一次；文档用相对链接引用。
- 只提交自查后的可公开图片与 Markdown；私人原件、完整日志、视频和大包放 private。
- 产品源码和构建产物保留赛事根目录，不复制到材料目录。
