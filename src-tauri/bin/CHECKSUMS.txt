调用协议 (实测验证):
  carapace <completer> export <tokens含命令名...> <当前词>
  输出: {"version","messages","noprefix","nospace","usage","values":[{value,display,description,tag}]}
  示例: carapace git export git checkout t  →  terax-clone-v0 (local branches)
  示例: carapace git export git switch -    →  --conflict/--create/... (longhand flags)
