# 演示视频放置目录

把宣传 / 演示视频放到这里，宣传页会直接引用；README 使用同目录的封面图。

## 怎么放

1. 视频命名为 **`demo.mp4`**（H.264 + AAC，建议 1920×1080、30fps、≤ 60 秒、体积 ≤ 20 MB）：
   ```
   website/assets/video/demo.mp4
   ```
2. 封面图 **`poster.png`**（16:9，1920×1080）已经放好，是宣传页首屏的真实渲染图；
   有了视频后建议替换为视频中的一帧真实界面截图。

## 会自动出现在哪

| 位置 | 引用 |
|------|------|
| 宣传页（GitHub Pages） | `assets/video/demo.mp4` — 原生 `<video>` 播放；文件不存在时显示占位说明 |
| `README.md` | `website/assets/video/poster.png` 作封面；GitHub 会过滤 `<video>` 标签，因此 README 用"封面 + 链接"方式提供入口 |

## 说明

- 宣传页部署的是 `website/` 这一层目录，所以视频必须放在本目录内，不能放到仓库根目录（那样会 404）。
- 录制前请隐藏真实 IP、账号、绝对路径与密钥。

## 建议镜头（30–60 秒）

1. 新建 SSH 工作区 → 连接服务器
2. 对 Agent 说一句排障/部署需求 → 命令逐字写入真实终端，在提示符处回显
3. 审批卡出现 → 确认执行 → 远端输出回流到工具卡
4. 资源管理器跟随 `cwd`，拖拽上传一个文件
5. 切到教学模式 → 单步命令卡，学生点击执行、结果回填后继续讲解
