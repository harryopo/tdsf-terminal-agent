# 项目状态

状态整理日期：2026-11-13。此页说明源码范围与已知验收边界，不代替接手时的 Git/CI 现场。

TDSF 是以终端为中心的桌面工作台，包含本地/WSL/SSH、文件浏览编辑与 AI 协作。技术基础为 Tauri 2、React/TypeScript、Rust 和 Python sidecar；生产 Agent 保持 Strands 单入口。

## 实现与验收分开

| 范围 | 当前读法 |
|---|---|
| 终端、文件、工作区、设置和编辑器 | 已有源码实现；不同平台与连接场景仍须按受影响范围实测 |
| Agent 执行、审批、工具卡与回显 | 已有生产链路；修改时必须验证身份绑定、失败/取消和输出归属 |
| 知识浏览、中文整理与原始参考 | 保留来源和私人数据边界，不把原始抓取量当有效知识质量 |
| 命令建议与纠错扩展 | 本地候选仍在评审与修正，不能称稳定交付 |
| 专用端侧模型与学习存储 | 有研究和隔离实验，尚不能称已接入生产 |
| 安装包与发布 | 源码版本不代表已发布或已验收；查看具体候选的安装验证记录 |

当前优先顺序为：安全和稳定边界、真实输入与连接归属、无模型完整交互、再扩展模型与长期运维能力。完整桌面/SSH/安装测试与源码、假服务及离线实验结果分别标记。

## 下一步方向

- 收口建议接受、异步过期和输入快照边界，保留 shell 原始按键语义。
- 完善命令参数、粘贴/编辑后的预测行为，并提供简短中文依据。
- 对独立安全依赖候选完成构建分诊和 Rust 验证，再评审整合。
- 以来源、资源和无工具调用约束评测端侧模型，不让模型进入逐键自动链路。
- 持续维护 SSH、资源管理器、知识内容与可追溯日志的真实使用路径。

详细设计见 [方案目录](plans/README.md)。研究建议不能直接当成产品已具备的功能；待批准事项不因文档整理而获批。
