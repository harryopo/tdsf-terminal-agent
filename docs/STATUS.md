# 项目状态

状态整理日期：2026-11-18。此页说明源码范围与已知验收边界，不代替接手时的Git/CI现场。共享审查分支产品起点210c787、后续治理文档已推，main仍未合并；成员按[当前工作包](../competitions/2026-huawei-agent/04-AI协作与交接/README.md)接续。

TDSF 是以终端为中心的桌面工作台，包含本地/WSL/SSH、文件浏览编辑与 AI 协作。技术基础为 Tauri 2、React/TypeScript、Rust 和 Python sidecar；生产 Agent 保持 Strands 单入口。
