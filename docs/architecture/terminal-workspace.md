# 终端、连接与工作区

终端界面基于 xterm.js；本地 PTY、WSL 与 SSH 是不同的执行目标。标签页和分屏叶子必须按自己的绑定选择终端，不能从全局活动连接猜测旧命令卡的归属。

## 输入与输出

用户原始字节、空格、引号、Enter、Tab、粘贴和输入法行为优先。增强显示不能改写命令、污染复制文本或伪造返回。终端已有 ANSI 颜色、Agent 输入着色和普通输出语义增强是不同链路。

候选只插入文本，不自动执行。未知输入不能当作空行；只在可信提示符、正常缓冲区、明确光标和空闲状态下恢复输入快照。输出渲染完成不等于 shell 已在接受输入。

命令块和真实开始/结束信号用于关联执行；不能在结束时补造开始归属。回显可用、退出码与 Agent 后续模型响应分段测量，避免把模型等待误判成终端延迟。

## 用户与目录

`su` 改的是 shell 用户，不会自动改变原 SSH 的 SFTP 认证身份。嵌套 `ssh` 也不自动建立新的文件连接。恢复目录跟随必须说明这一区别，不能往疑似密码输入框自动注入命令。

连接断开后的终端不应静默转成本地执行。对“连接中/重连中且暂时缺句柄”的中间态同样需要验证，不能仅覆盖最终断开。
