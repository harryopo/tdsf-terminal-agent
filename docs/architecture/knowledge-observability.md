# 知识、运行记录与置信度

知识内容区分官方/内置资料、用户自己的整理及爬虫原始参考。语言不决定归属；旧中文翻译不应因原文库变化被覆盖，原始抓取内容也不直接等于整理后的有效知识。

内容导入需要来源、冲突处理与可恢复性。私人库不随源码或安装包分发；本地预览导出与运行数据库不是源码资源。后续联网检索的站点限制与不可信内容边界另做设计，不冒充已有能力。

[置信度面板](../../src/modules/ai/components/ConfidencePanel.tsx)沿用对话右下角浮窗，集中展示对话、模型已返回内容、工具与执行流程；聊天保持简洁。模型返回的思考文本与隐藏内部状态分开，不能声称记录了 SDK 未提供的信息。

证据应可定位到调用、目标、时间、输入/输出、状态和截断情况。已有工具记录、终端阅读兜底与确认过的退出状态有不同证明能力；覆盖率或规则分数不是校准后的成功概率。

已返回思考内容的本机查看与日志导出分开；导出默认不包含思考，显式选择后才包含。凭据、环境提示词和隐藏 SDK 字段仍不属于导出范围。
