# 目录与文档治理方案 v1.0

日期：2026-11-13。状态：用户批准实施。范围：文件目录、文档归属、协作入口与公开边界；产品源代码和依赖不变。

## 目标

保留源码原结构，文档按主题，比赛集中，AI 任务和私有证据隔离。新接手者能从规则、当前断点、专题方案定位代码和验证，不必通读多份巨型日志。

## 归属

正式说明在 `docs`；比赛在 `competitions/<event>`；任务在 `.ai/tasks/<id>`；历史交接按月；原始验证在 `.ai/test-runs`；独有历史保留在 `.ai/archive`；参考和临时导出在 `.local`。周报路径保留，实际源码/数据/构建路径不为整齐而搬动。

官网仍是独立源码目录，改版材料归官网专题。比赛只引用产品能力，不复制产品源码另建“参赛版”。未知赛事材料标未确认，不擅自并入火山杯或华为比赛。

## 执行与保护

先留源码指纹和原件备份，生成逐文件去向，再做核绝对路径、不覆盖目标的迁移。失效索引、可生成 PDF 页预览与排版临时文件可删除；唯一原稿、失败证据、许可证及用户数据保留。

冻结回执与合同不因新索引改写审批结果。历史引用通过迁移表追溯；现行文档更新链接与替代关系。公共文件按白名单审阅，私人材料默认忽略。

## 验收

- 计划中的文件均能对应保留位置、删除依据或明确受阻记录。
- 新公开文档和入口链接有效，且不会依赖仅本机存在的私有目标。
- 源码、锁文件、构建资源与原有其它 AI 候选指纹不变。
- 旧入口退出当前阅读路线；工具适配只引用统一规则。
- 如实记录整理失败与恢复，不把文件验收称产品全绿或发布许可。
