# 模型行为与 Token 实施任务卡 v1.0

日期：2026-11-20；任务：TEAM-AGENT-03；状态：待评审、未授权产品实施。基线 `f40e9d1adb06050dcabb417bc4aaefa8da5fbfe5`。GPT 主代理负责架构、安全、集成与验收，其他 AI 只能修改被分配文件；本任务不覆盖 Echo PR56 的 D1/D6/D7。

## 1. 共同约束

- 保持 Strands `main` 单入口，不在前端 fallback 增加新执行能力。
- 每阶段先写失败反例，再做最小实现；不用降低断言、跳过失败或真实付费模型换通过。
- 配置、usage、日志和审计分离；不保存命令原文、prompt、response、密钥或完整主机信息。
- `adapter.py` 只做窄接线，纯函数独立文件；PR56 风险和脱敏文件不在写范围。
- 每阶段保留完整 SHA、命令、退出码、环境、失败和未做，文档与代码同 PR，队长决定合并。

## 2. 阶段与任务分配建议

### T0：基线、合同与离线评测骨架

**负责人：**GPT 主代理；独立测试 AI 复核。
**文件：**新评测/测试目录、`model_params.py`、`turn_policy.py`、`usage.py` 的空接口或纯函数测试，不改生产调度。

- 固定现有 UI 温度漏传、RPC 默认值、Provider 能力和 usage 会话丢失反例。
- 建立不少于 30 个合成运维场景：普通命令、巡检、诊断、教学、生产变更、多方案请求、歧义输入。
- 冻结输出 profile、GenerationConfig、ModelCapabilities、UsageEvent 和路由“权限不变”合同。
- 明确温度对比只测稳定度，不承诺逐字确定。

**完成门槛：**合同评审通过；反例在基线按预期失败；无真实模型调用；PR56 文件零改动。

### T1：模型生成参数与思考能力闭环

**负责人：**CodeArts 负责偏好/设置/同步，GPT 主代理负责 `agent_facade.py`、`model_params.py`、`model_adapter.py` 核心接线。

- 修通 temperature/max tokens 全链，覆盖 0、0.1、null、非法值和旧配置迁移；Anthropic null明确为应用默认8192，回执区分requested/effective，思考预算小于effectiveMaxTokens。
- 增加thinking/effort和代码验证的Provider能力；用户声明不能把未知端点提升为发送白名单。
- showReasoning仅保存在前端Preferences并控制展示，不进入agent.configure/LLMConfig/模型工厂，不触发重建；模型参数单独返回applied/warnings。
- 设置页提供稳定运维默认值、能力禁用原因、显式保存与失败回滚；回合绑定配置快照，在飞请求不受新配置影响。

**验收：**UI→RPC→工厂假服务测试；未知兼容端点不注入 reasoning；key 不落盘；showReasoning 不宣称停止推理或日志。

### T2：确定性意图与输出合同

**负责人：**GPT 主代理；独立 AI 做路由对抗复核。

- 实现显式模式/技能优先、高置信规则和 `general` 默认。
- 将普通问答、巡检、诊断、命令输出 profile 窄接入现有 prompt 构造。
- 只给首选方案，备选带触发条件；不主动诱导或新增保存隐藏思维链，不增加分类模型请求；Provider既有reasoning展示/日志不在本任务改变。
- 路由前后 permission mode、工具集、真实 target 完全不变。

**验收：**路由纯函数 100% 可预测；风格基准首选唯一性目标 ≥90%、必需结构完整率 ≥95%、权限/目标保持率 100%。指标是验收目标，不是当前实测结果。

### T3：usage 归一化、幂等和会话恢复

**负责人：**GPT 主代理负责 Python 调用边界，CodeArts 负责前端映射和会话 store，独立测试 AI 做事件重放。

- 抽离 `_extract_tokens`，补 total/reasoning/cache/semantics 和未知字段。
- MVP建立独立 `.tdsf-data/usage.db`：usage_events的eventId唯一约束支撑跨重启/迟到重放，日期/Provider/模型/会话可查询；session_usage_summary长期保留，明细清理不归零。
- 覆盖工具循环、max tokens续跑、追加验证、取消、异常、degraded和重放；SessionMeta只作可选缓存，不承担趋势或持久去重。
- 实报与估算隔离，事件不含敏感正文；sidecar汇总/趋势RPC和前端会话/设置页使用同一数据源。

**验收：**合成事件跨进程重启重放仍幂等，aggregate/delta不重复，筛选和短期趋势可由事件重建，会话摘要与设置汇总同源；先证明追加轮覆盖再宣称完整。

### T4：会话摘要与设置用量面板

**负责人：**CodeArts；GPT 主代理审查数据合同和 UI 安全。

- `AiMiniWindow` 显示最近请求、会话汇总、模型拆分和配置快照。
- 设置页增加日期/Provider/模型/会话筛选、Token 分项和短期趋势。
- 加载、空、失败、未知、估算分别展示；事件驱动刷新。
- MVP 不新增图表重依赖、不做计费中心、不自动联网定价。

**验收：**组件测试、设置迁移、筛选一致性、隐藏窗口刷新策略、typecheck/lint/Vitest；原生视觉另行留证。

### T5：整包回归与队长验收

**负责人：**GPT 主代理/ROOT，独立测试 AI 复核，队长决定合并。

- 跑前端、Python、必要 Rust 和真实框架注册回归，保留全部失败。
- 原生验证设置保存、跨窗同步、在飞配置隔离、会话重启恢复和用量面板。
- 真实模型仅使用明确授权的测试额度和合成运维任务，按 Provider 记录能力差异，不默认执行。
- 核对 PR56 集成后的冲突和新 HEAD，旧评审不覆盖新提交。

**交付：**一个完整 Draft PR，包含实现、测试、更新说明、截图/证据和未做清单；未授权真实模型时明确未测，不阻塞离线包评审。

### T6：微调评估另案

只有 T0–T5 数据证明输出仍不稳定，才提交独立方案：数据来源与许可、脱敏、训练/验证拆分、基线对照、资源、回退和生产准入。未重新批准前不训练、不上传、不打包权重。

## 3. AI 文件分工与冲突规则

| 角色 | 可负责 | 不得修改 |
|---|---|---|
| GPT 主代理 | 总体合同、`model_params.py`、`turn_policy.py`、`usage.py`、adapter 窄接线、集成验收 | 未经队长批准的真实模型、权限策略、PR56核心安全语义 |

| 独立测试AI | 指定测试文件、假服务、反例和机械复核 | 生产实现、断言放宽、真实服务器/模型 |

共享文件发生冲突时保留双方改动和反例，由 GPT 主代理/ROOT做精确差异集成，不整文件覆盖。
