### 已复现的三项阻断

1. `openCorrection` 等词表期间关闭，promise 返回后面板仍 `visible=true`。只在最终结果检查 version 不够；关闭本身必须使在飞请求过期。
2. 方向键使输入失真后，`writeCompletionLine` 仍返回 true。清掉内存缓冲不等于用户真实输入为空；不能将候选写进未知光标处。
3. 本地 Bash DEBUG hook 报第一段 `$BASH_COMMAND`，而提示符结束事件带整行最后的 `$?`。隔离执行 `printf ROOT_OK; __tdsf_readonly_missing_test__`，得到 `633;E;printf ROOT_OK` 和 `133;D;127`，成功的第一段被错误绑定为失败。

C3 优先保持原终端行为，新增内部完整性/归属字段可行，但不能静默改现有 OSC 含义或放宽 Agent 执行回执。不能靠 `history 1`、渲染文本或单个 `$BASH_COMMAND` 拼出自称完整原文。若当前 shell 无可靠完整捕获，允许安全降级：保留真实输出，明确片段/未知，停用该块的学习与自动纠错，不冒充准确执行证据。若要求重写公用输入/执行协议，保留降级路径并提出单独变更，不擅自替换整套架构。

## 3. TEAM-AGENT-03：模型行为与用量整包

负责人：现有 Agent 模型规划 AI / CodeArts。基于自己的隔离候选连续做 T0–T5，允许前后端真实代码；ROOT 不要求每个纯函数和接线都由自己亲写。原三份 v1.0 PRD、技术方案、任务卡保留为输入，本节是必须落实的合同修订。

### 3.1 冻结的架构边界

- Strands `main` 是批准入口。新能力在配置/readiness 失败时明确停止，不能导向前端 AI SDK 执行兜底；现有 fallback 单独登记收口，不借本任务扩大或全仓删除。
- `showReasoning` 只影响展示，不进入模型配置、不触发重建，也不声称关闭推理或日志。仅沿用提供商已返回、现有政策允许的内容，不索要隐藏思维链。
- `model_params.py`、`turn_policy.py`、`usage.py` 等窄模块承载确定规则；`adapter.py`、facade、工厂只接线。普通问答/巡检/诊断/命令/教学 profile 不改变工具、权限、审批、目标、模型或执行策略，不新增分类模型请求。
- 输出合同不合格时保留真实正文、工具结果、失败/取消/未知状态，提示格式问题或做不改事实的展示；不能丢弃真实结果后捏造一个「完整短答案」，也不额外调用模型修格式。

### 3.2 参数与能力

- 低温度 0.1 是已支持模型的工程默认建议，不是确定性保证。保留旧显式用户设置；0 合法，null 与未设置明确区分，非法值拒绝。能力不支持时省略字段并回报原因，不猜测参数。
- 能力识别至少考虑 provider、协议、模型和端点类型；未知自定义兼容端点默认不发送高级 reasoning 参数，不接受任意 providerOptions 透传或付费探测。
- requested/effective 参数与配置代次、回合快照形成真实回执；同步失败不能沿用旧模型发送。不同 API 的输出上限参数分开适配，Anthropic 预算式与新模型 adaptive thinking 不能套同一规则。
- 合成 30 场景、假 Provider、录制 fixture 用于接口、路由、计数与错误边界；不能据此宣布真实模型答案质量/温度效果达到 90% 或 95%。本包不用真实付费模型，模型质量仍注明未测。

### 3.3 用量事件与持久化

| 合同 | 要求 |
|---|---|
| 身份 | 事件源产生稳定 call/attempt 身份和单调 revision；重传沿用身份，不能每次投递生成新 UUID 绕过去重 |
| 粒度 | 明确 `model_call` 与 `invocation_aggregate`；缺实际逐调用事件时只报聚合，不虚构精度；聚合与其覆盖的子调用不能重复入总数 |
| 更新 | 明确 `cumulative`/`delta`；同一请求的流式快照与最终回执按 revision 更新，不能忽略最终值，也不能相加两次 |
| 单位与未知 | input/output/total/reasoning/cache 等保持提供商语义；缺失用 null，实际 0 才记 0；reasoning 常是 output 子集、cache 常是 input 子集，禁止全字段盲加 |
| 事务 | 原始去重、修订与摘要在 SQLite 事务内原子更新；跨会话/重启/乱序/重复/取消测试；不完整覆盖明确标记 |
| 边界 | 用量失败不重试模型或重放命令；不把摘要当费用账单；不存 prompt/正文/命令/凭据/完整主机标识 |
| 保留 | MVP 不自动删除账本；「近 90 天」只作查询范围，不冒充保留策略。后续清理必须另有汇总、去重存根/水位与恢复证明，不能删除后重复计费式统计 |

Strands 只提供聚合指标时先诚实使用聚合；必须覆盖内部工具循环、后续生成、失败与取消，不仅最外层最终消息。前端会话摘要和设置图表共用后端事实源，CSS/SVG 即可，不新增大型图表依赖。
