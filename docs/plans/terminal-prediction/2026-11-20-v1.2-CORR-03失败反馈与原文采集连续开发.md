### P0：完整性硬边界

本地Bash的512字符上报上限不能与`commandComplete=true`同时出现而不保留原文。优先最小修复：超限/经过破坏性截断或控制字符清洗时将完整性降为false，保留已有显示截断；不擅自取消上限或把任意长输入写进日志。逐条验证Bash本地、SSH Bash、zsh各自长度规则，不能只改一个实现。

数字字段要求严格十进制正整数、有限且安全的范围；`1junk`、小数、符号、空值、溢出、额外字段、错误nonce、迟到/冲突标记均不提升为完整。保持旧协议未知状态与本轮新增无效证据的区别，不能把畸形F悄悄当作可靠旧格式继续学习。合法标记正向路径、片段false及nonce隔离不回退。

### P1：反馈与不打扰

只在可信的用户单命令127完成、真实scope仍当前且提示符可证明空时，使用现有面板给一次简短反馈，如「上一条命令未找到，暂无可靠纠正建议」。无词表、无词形、风险隐藏分别给准确原因；风险未知不能说成「系统没有该命令」。不要解释用户不关心的内部字段。

去重键至少为scope代次+block id，不以命令文本永久去重；能重复执行的同一命令应按新block判断。等待期间用户开始下一行、切leaf或取消即作废；不在稍后清空行时补弹旧提示。空候选面板不抢焦点，Enter/→继续原终端语义，Esc只关闭。行内停顿自动检测仍可无候选静默，避免每次拼写未完成就刷提示。

### P2：算法决定与预授权门槛

**不把任意乱码强行纠正成某个命令。** `llll`等短串允许没有候选，解决的是反馈可信，而非保证总有推荐。

1. 当前自动/首层推荐仍只做单编辑，不改变已有首选排序。缺省不做重复字符折叠、不扩到参数值或路径，不修改其它token或加入sudo。
2. 可新增一个「更多词形候选」显式次级动作；仅该动作采用有界相邻换位编辑距离≤2。输入命令名长度5～64、候选名至少4字符，距离/两者最大长度≤0.4；2～4字符仍只允许原单编辑。最多显示3条，不代表语义置信度或执行建议。
3. 候选仅来自当前leaf/连接作用域实得的可用命令表；完整候选仍走现有RPC风险复核，L2只回填、L3/L4/unknown不显示。终端错误输出、互联网提示、未安装软件名不能绕过词表。
4. 复用已有实现/开源纯算法前核许可证和测试；不加重依赖。若需小型有界纯函数，先独立测试，不同时重写tokenizer、ranker和输入链路。
5. 至少覆盖：合法命令负例、常见单编辑、二次编辑、重复字符、短串歧义、alias/函数/路径/引号/复合/参数不变、未安装与高风险候选、过期owner。以固定公共/合成语料比较旧版和新版，所有禁止类别必须零放行；旧自动层候选输出必须保持一致。
6. 在固定词表和硬件记录候选召回、歧义、排序及p50/p95耗时。10k命令表单次P95以30ms为工程目标，未达先优化或保留实验，不放入逐键同步主路径；微基准不作易抖CI硬断言。合成覆盖不是自然用户准确率或算法原创证据。

以上门槛通过后，**实施AI直接完成次级入口接线和测试**；不必再把「是否允许距离2」交回审批。门槛未通过则交实验及保留旧生产层，不降低门槛换上线。

### P3：原文捕获专项的技术裁决

zsh已经使用`preexec`，先验证其第一个参数、空值、alias、重复、历史过滤、引用与长度处理，不重复造第二套hook。Bash的`$BASH_COMMAND`是执行片段，不等于用户原文；history推进不是所有交互命令的可靠证据。

| 来源 | 本包权限与决定 |
|---|---|
| zsh原生preexec首参 | 可在现有hook内修正escaping、截断与来源判定；保留隐私/完整性/单命令和scope守卫，无可靠原文时降级 |
| TDSF已知输入行观察 | 可做只读关联原型；必须证明提交→exec→结束一一归属，覆盖粘贴、Tab/历史、IME、程序读取stdin和Agent逐字；不能将内存缓冲猜测直接当权威原文 |
| 已存在的开源shell集成 | 优先调研真实hook API与许可证，仅探测用户已经安装且明确公开的能力；不自动安装ble.sh/bash-preexec或覆盖用户trap |
| bind -x / READLINE_LINE | 允许在隔离临时HOME的实验shell做原型并记录兼容性；**不批准写入产品接管Enter、vi/emacs键图或用户配置** |
| 放宽history/静态推测alias | 不允许，不以“首词是alias”或与上次相似来放行 |

原型的负结论也是完整交付，不为追求覆盖写出一个新shell编辑器。最多一个专项阶段后形成来源/行为/侵入/证明矩阵；若只剩Enter接管或公用协议语义重写，保留保守产品路径，交可复跑研究结果即可，不让其它步骤停工。

可直接生产接线的门槛：来源已由现有shell/宿主提供；不改变提交语义、用户绑定和历史策略；原文与真实block一一归属；同一新block的alias/重复能可靠识别；丢包/截断/歧义拒绝；旧协议兼容。保持当前E/F含义，额外来源只作内部可选元数据；不擅自引入新的公用OSC命令。无法满足时不接线，不需要为了阶段收尾反复申请豁免。
