# 输入与建议边界 v1.0

日期：2026-11-13。状态：ROOT 架构评审确定的修订方向；实现与正式 F0 准入尚未完成。范围：现有终端上的预测、纠错与后续候选生成，不创建另一套 Shell。

## 任务分开

当前行补全、下一命令推荐、当前行/失败块纠错和显式意图生成共享可信上下文与接受守卫，但分别定义触发、候选池、排序与指标。

优先规则/统计和现有规格、历史、Carapace 等能力。专用模型只在用户明确请求生成或辅助分析时评测；不因置信度低、停顿或一个总开关自动调用。

## 输入与归属

输入快路径记录真实发送文本。仅在可信 shell 集成的提示符边界、正常缓冲区、明确空闲与光标条件下，用终端逻辑行交叉校验。未知不是空行；不能按提示符正则剥屏幕文字，把密码或输出当输入。

保留空格、引号和字节；词法分析只决定候选位置。可靠单行粘贴可重建，多行、控制字符、密码、忙态、全屏程序等不确定情况弃权。

每次接受重验活动终端、真实连接、输入版本、提示符和空闲状态；输入/目标改变、关闭或取消后，迟到结果必须失效。明确选择只插入文本，不执行。

## 交互与纠错

一次只呈现一种可接受建议。显式请求优先，其次可靠失败纠错，再其次停顿纠错。自动提示不抢终端焦点、不拦 Enter；Tab 继续交 shell。

失败纠错首版只限可靠用户简单命令的“未找到命令”127，并在可靠新提示符后提示。普通非零、脚本内部错误、未知退出状态不能据此自动纠正。

下一步建议保留显式入口，增加可见按钮并统一快捷键。整段灰字展示在输入与接受边界稳定后实施。

## 分期与验收

先完整命令风险边界、接受/异步，再真实开始结束归属和输入合同；之后确定有界存储与纯展示接口。正式 READY 绑定实际文件和指纹，不能只给不包含未提交文件的 HEAD。

固定反例覆盖输入变化、切终端、连接更换、关闭后迟到、块来源与 Enter；补粘贴、输入法、行中编辑、重连和用户切换的正反场景。真实键盘/SSH、组件与离线回放分开报告。
