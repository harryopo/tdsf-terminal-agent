| 专题 | 当前范围 |
|---|---|
| [产品总方向](product/README.md) | 长期目标与旧总纲版本分开，当前按专项推进 |

| [Agent 运行时](agent-runtime/README.md) | 保持单运行时，改动按真实工具链验证 |
