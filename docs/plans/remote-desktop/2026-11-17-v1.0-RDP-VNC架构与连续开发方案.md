# RDP / VNC远程桌面：架构与连续开发方案 v1.0

日期2026-11-17。负责人Yan-0914；架构/验收ROOT＋队长。状态：**队长已明确要RDP/VNC完整远程桌面，并授权先深度调研/可行性分析，再自主实现；不逐步等待审批。** 不是运维仪表盘，也不是只改终端配色。知识库/Skill保留为备用，不与本包抢主线。

**Goal:** 在TDSF原生窗口内连接RDP/VNC、显示真实远端桌面，完成用户键鼠操作、会话切换/关闭和可解释的失败恢复。
**Architecture:** 现有React/Tauri/Rust不换框架；远程桌面是独立模块，由Rust管理连接/凭据/生命周期，成熟开源协议栈提供协议与解码，前端只负责本地受信UI与画面/输入适配。Python Agent、SSH PTY、SFTP各保持原归属。
**Tech Stack:** React/TypeScript＋现有UI/状态管理；Tauri2/Windows WebView2；Rust异步会话主管；优先IronRDP与noVNC；FreeRDP为已授权替代候选。具体版本由调研/PoC验证后锁定，不按仓库latest盲升。

## 三、分层架构：控制面与画面/输入数据面分开

```text
现有连接/工作区入口 → DesktopProfile（元数据） → DesktopSessionHost（桌面标签/工具条）
                                              ↓ 控制IPC：连接、关闭、尺寸、认证挑战
Rust DesktopSessionManager（owner窗口/会话代次/状态/取消/资源/凭据/信任）
    ├─ RdpEngine：IronRDP优先；FreeRDP候选经统一适配边界接入
    │       ↔ TCP/TLS/NLA ↔ RDP服务端
    └─ VncTransport：受控本机桥接 ↔ 已选择的VNC服务端/明确SSH隧道
            ↔ noVNC RFB core ↔ 本地画布与键鼠事件
画面/协议数据：有界、有序、可取消；不走Python Agent或全局JSON事件广播
```

| 层 | 职责与约束 |
|---|---|
| DesktopProfile | 新协议元数据隔离命名空间，含id/protocol/host/port/显示名/可选username/credentialRef；不能把RDP用户当SSH文件身份 |
| DesktopSessionManager | Rust为会话唯一主人，随机sessionId＋generation；连接任务、bridge/帧缓冲、owner窗口与取消清理；不借全局activeSSH猜桌面归属 |
| RDP适配 | 优先复用官方connector/session/图像与输入处理；画布只做成熟解码结果的呈现，不重写协议。官方web组件若需要网关，必须如实计入，不能隐去依赖 |
| VNC适配 | noVNC保留完整RFB处理，Rust做TCP/隧道及受控WebSocket字节桥接；桥接本身不解析/执行远端文本 |
| 前端呈现 | 独立DesktopSessionHost，黑白灰、紧凑工具条、协议/目标/安全状态清晰；不新增第二套左边栏 |
| 现有模块 | local/WSL/SSH终端与SFTP保持原流程；桌面断开不得落成本地shell，Agent默认没有桌面输入接口 |

### 3.1 接口合同（概念合同，具体Rust/TS签名可自主落地）

- profile：协议/目标/非秘密选项，凭据只引用现有secrets服务；临时目标同样先由Rust校验并冻结到会话。
- connect(profile/options)：Rust从真实调用窗口确定owner，返回sessionId/generation/协商能力；不信任前端自报owner。
- input(sessionRef, sequence, event)、resize(sessionRef, size)、disconnect(sessionRef)：按owner＋代次＋状态校验；关闭幂等，迟到事件不作用于新连接。
- 状态/挑战/帧元数据都带sessionRef和序号；秘密不进入事件/Debug日志。旧桌面标签恢复为断开态，不隐式批量登录或重放输入。
- 前端可以新增本模块兼容辅助接口/字段，不必逐项问；不能破坏原SSH/Agent RPC或旧工作区恢复数据。

### 3.2 传输与渲染选择（通过PoC定，不锁死猜测）

Tauri官方说明全局event不适合大消息/高吞吐，优先评测定向Channel或受控二进制通道；状态控制用小消息，画面不每帧base64塞全局事件。noVNC官方RFB支持WebSocket连接及wsProtocols，这提供桥接候选，不等于TDSF已接通。

- 首选本地内存有界队列/二进制传送，最多保留有限在途画面；图像可丢弃过时帧，按键释放/点击等输入不能随意丢。
- 如noVNC需真实WebSocket，**本任务已授权**在模块内实现仅127.0.0.1临时端口的本机桥接；生命周期绑定会话，Origin/host检查、随机短期一次性能力票据、目标固定、关闭/超时回收。优先经子协议/内存传票，不把密码放URL，不提供任意TCP目标参数。
- 可在候选内选择原生Rust呈现、官方web渲染组件或Canvas适配；若不满足性能/焦点/分辨率，保留测量后自主调整。不得通过关闭CSP、开放0.0.0.0、允许任意远程网页Tauri权限来解决。
- WebView只加载打包的本地UI/协议代码；远端桌面是像素/协议流，不是把远端HTML装进带本地权限的页面。

## 四、认证、输入和生命周期的明确边界

| 事项 | 必须行为 |
|---|---|
| 凭据 | Windows沿现有secrets服务/系统凭据库，按协议/完整目标/用户名隔离引用；不写localStorage/普通profile文件、不上CLI密码、不打印认证/输入/剪贴板内容 |
| RDP安全 | 检查协商TLS/NLA及实际库行为；证书链/名称问题和首次自签名确认要明确，保存指纹后变更拒绝/重新显式决定；不能accept-all或静默降级 |
| VNC安全 | 识别服务端实际安全类型，不把经典VNC认证当加密；默认优先SSH隧道或已验证加密通道，直连未加密需用户清楚选择/警示，不静默启用公网裸连 |
| 信任域 | RDP证书/VNC端点与SSH known_hosts分开；不能为了桌面功能改原SSH信任策略。复用SSH隧道时保持主机核验，只释放本模块隧道，不断开他人SSH |
| 输入 | 仅桌面内容实际聚焦时转发，沿成熟协议库键鼠映射；焦点丢失/标签切换/断开释放修饰键，避免粘键或后台错发 |
| 快捷键/中文 | 区分客户端关闭/切换与远端组合键，提供显式发送特殊键入口；按实际协议验证中文路径，不能以一段模拟字符串假称IME支持 |
| 剪贴板 | 首期仅可选文本，默认不自动双向同步；显式启用/粘贴，标明方向；不读文件剪贴板、不接磁盘/设备重定向 |
| 重连 | 可实现有界重试，但不得重放过去键鼠/剪贴板，也不把证书变更当普通网络重连；UI不伪造已连或保留旧帧当新成功 |
| 资源 | idle/connecting/authenticating/connected/reconnecting/disconnecting/closed/failed状态清楚，取消/关闭真实停止网络任务、队列与bridge；旧generation失效 |
| 日志 | 只记脱敏目标引用、阶段、状态码、耗时/字节/队列/资源计数，不保存画面、密码、用户按键原文或剪贴板；截图由人实际留证并自查 |
