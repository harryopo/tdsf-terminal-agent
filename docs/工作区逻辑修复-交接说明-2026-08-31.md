## 二、核心逻辑变更（Agent 感知必读）

### 1. Space 类型由"创建意图"决定，连接不再改写它
- **旧**：任意 SSH 连接成功 → 当前 Space 升级成 SSH（污染本地/WSL）。
- **新**：SSH 连接成功**只绑定专属 SSH Space**（`env.kind==="ssh"` 且 host/user 匹配）。
  - 自动连接（开机）：无匹配 Space → **直接跳过并断开孤儿会话**，绝不凭空新建（`App.tsx` 订阅处理器 + 启动 effect 双重保证）。
  - 手动连接（对话框/SSH 面板）：无匹配 Space → 新建一个 SSH Space 并切换。
- **结论**：`activeSpace.env.kind` 现在**严格等于**用户创建时选的 `local`/`wsl`/`ssh`，不会被后台连接偷偷改掉。Agent 读它是可靠的。

### 2. 删除 Space = 关闭其 SSH 连接
`handleDeleteSpace` 删除前取出该 Space 绑定的 session，若无其他 Space 共用则 `disconnect()`。后台不再有孤儿连接。

### 3. 断线/启动降级会同时清 env 和 root
- 会话断开 → 绑定它的 Space 降级 `{kind:"local"}` + `setRoot(null)`（不再残留远程路径导致 InvalidPath）。
- 启动幽灵 SSH Space 清理（6s 兜底 + 自动连接失败分支）同样 `setEnv(local)` + `setRoot(null)`。

### 4. 新建本地 Space 的 root/env/cwd 强制本地
`SpaceCreateDialog` 的 `defaultEnv`：当前是 SSH 时降级为 `LOCAL_WORKSPACE`；`defaultRoot`：仅本地 Space 才继承 cwd，否则回退本地 home。WSL/SSH 终端下新建本地工作区不会再拿到远程路径。

### 5. SSH tab 标题统一为 "shell"（用户钦定 2026-08-28）
订阅处理器绑定 tab 时 `customTitle:"shell"`（原来设成 `user@host`，与 Space 名/状态栏重复）。

## 三、Agent 如何感知"当前工作区环境"（对接点）

数据源在 `src/modules/ai/lib/useAiLiveBridge.ts`（`LiveSnapshot`）+ `App.tsx` 的 `getLive()/getEnvBlock()`。注入给 Python agent 的 `<environment>` / `<terminal-history>` 分区字段：

| 字段 | 取值逻辑 | 新逻辑下的语义 |
|------|---------|--------------|
| `workspace_root` | `explorerRoot ?? launchCwd ?? home` | 当前 Space 的本地根目录（SSH Space 为远程路径） |
| `active_terminal_cwd` | SSH 优先读 `sshStore.currentPathBySession[activeSessionId]`，否则 tab leaf cwd | 已按 Space 隔离，不会串到别的 Space |
| `ssh_session_id` | `getSshRustSessionId()`：仅返回 **connected** 且 rustSessionId 非 null 的活跃会话 | **非 null 即"当前工作区连着 SSH"**；null 即本地/WSL |
| 环境探测 | `system.probe_env`（os-release/内核/shell），会话级缓存 | 判定 Windows vs Linux 发行版 |

**给 Agent 对话的判定建议**：
1. **是否 SSH 工作区**：读 `live.getSshRustSessionId() !== null`，或读 `useSpaces.getState().activeSpace.env.kind === "ssh"`。两者现在同源一致（旧逻辑下可能背离）。
2. **Windows vs Linux**：`env.kind==="local"` → Windows pwsh；`"wsl"`/`"ssh"` → Linux。命令预测/解释按此分支。
3. **cwd 归属**：`active_terminal_cwd` 已按当前 Space 隔离，Agent 执行命令/读写文件应以此为准，不要回退到全局 launchCwd。
4. **后台无孤儿连接**：现在删工作区即断连接，Agent 不必再防御"连着服务器但工作区显示本地"的脏状态。

## 四、UI 变更（不影响 Agent 逻辑，仅告知）

- **顶栏工作区横向标签**：`SpaceSwitcher` 触发器从"当前名 >"改为每个 Space 一个横向 chip（图标+名），点非激活 chip 直接切换、点激活 chip 打开总览面板（重命名/删除/管理 tab 仍在面板里），行尾 `⌄`（总览）+ `+`（新建）。Space 多时横向滚动。
