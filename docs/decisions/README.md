# 已确定的长期边界

以下是延续既有决定的整理，不是新功能已实现的声明。

| 决定 | 影响 |
|---|---|
| 保持 Strands 单一生产 Agent | 不恢复旧运行时或双入口 |
| 真实终端与真实回显 | 不通过改写命令、伪造输出或静默重放来掩盖失败 |
| 知识按来源管理 | 内置、私人整理和原始参考不因语言或数量合并 |
| 追溯面板保持对话右下角浮窗 | 与原有布局统一，不另造左侧置信度页面 |
| 专用模型只给候选 | 先完成来源、资源和显式调用评测，不进入逐键自动链路 |
| 证据等级如实表达 | 源码/假服务、原生、真实 SSH、模型和安装验收分别记录 |

后续重要决定按日期增加独立文档，说明原因、取舍、范围、替代关系和确认依据。普通实现细节不必制造新的决策文件。

有分歧时可用 `YYYY-MM-DD-主题-讨论.md`，明确“待商议”，保留双方方案、对应提交、依据与风险。队长与ROOT决定后追加结论/日期/理由，不删成只有一方意见。讨论稿不是已批准架构，敏感漏洞细节不公开。
