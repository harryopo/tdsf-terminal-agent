# 远程桌面开源来源初核与待证事项

核验日期2026-11-17。ROOT读官方仓库README/API/许可和Tauri文档，并核当前项目入口；**没有运行远程桌面原型，也不是深入调研已完成。** Yan必须沿方案继续审代码/构建/真实PoC，不能把此表直接改成可行性通过。

| 一手来源 | 当前可确认 | 仍需验证 |
|---|---|---|
| [IronRDP README](https://github.com/Devolutions/IronRDP) | Rust模块化RDP栈，应用需提供传输/运行时；README标MIT OR Apache-2.0，GitHub元数据仅给Apache-2.0 | 锁定选用crate/组件的实际许可证、版本/MSRV、TLS/NLA/证书接管、图像输入和WebView2呈现，不以README能力代表本项目能力 |
| [FreeRDP README](https://github.com/FreeRDP/FreeRDP) | 原生RDP实现，官方说明Apache许可 | FFI/客户端API、DLL/ABI、编译与transitive codec依赖许可/资源成本 |
| [noVNC API](https://github.com/novnc/noVNC/blob/master/docs/API.md) | RFB使用WebSocket，构造参数可为WebSocket/RTCDataChannel；支持wsProtocols | 本地Rust桥接与Tauri生产Origin/CSP、安全类型、输入/中文/缩放实测 |
| [noVNC LICENSE](https://github.com/novnc/noVNC/blob/master/LICENSE.txt) | core为MPL2.0；界面/图片等文件许可有差别，不能笼统视全项目同一许可 | 只集成需要core，逐文件保留/核分发义务，不搬图片/主题造成误归属 |
| [Guacamole架构](https://guacamole.apache.org/doc/gug/guacamole-architecture.html) | browser client与guacd分工，服务端代理解释协议并连接远端 | 运行/打包/运维成本；本包不默认部署外部网关 |
| [RustDesk仓库](https://github.com/rustdesk/rustdesk) | 仓库元数据为AGPL-3.0；可作体验对照 | 不默认直接复制或误当RDP/VNC原生客户端库 |
| [Tauri Channels](https://v2.tauri.app/develop/calling-frontend/) | 官方不建议用普通全局事件承载高吞吐/低延迟大数据，Channels为有序流设计 | 实际二进制路径、队列/背压/焦点/关闭与本机性能 |
| [Tauri capabilities](https://v2.tauri.app/security/capabilities/) | 本地打包代码与远程来源权限不同，Rust调用仍须自行校验范围 | 新command/窗口owner权限、loopback桥接防外站滥用，不扩大远程网页权限 |

## 当前TDSF可接入事实

React/TypeScript界面、Tauri2/Rust系统后端、现有secrets平台存储、SSH/SFTP/隧道与工作区/标签已存在；当前未找到生产RDP/VNC模块。新模块用独立协议会话/凭据引用，不能把终端文本输入链充当桌面协议或混用SSH文件认证身份。首期Windows沿secrets系统凭据后端；其它平台原有后端能力有差异，不能声称所有平台都已加密存储。
