# 项目文档

本目录维护经过整理的项目说明。当前实现以源码为准，状态、方案、研究与历史记录分开；日期最新的文件不自动成为已批准方案。

| 需要做什么 | 入口 |
|---|---|
| 新组员先建立认知 | [五份入门文档与两人审查任务](development/team-onboarding.md) |
| 确认共同代码纳入范围 | [共享基线与保留候选](development/shared-baseline.md) |
| 了解当前范围与待办 | [项目状态](STATUS.md) |
| 理解系统与代码入口 | [架构地图](architecture/README.md)、[模块索引](architecture/modules.md) |
| 修改 Agent、工具或风控 | [Agent 链路](architecture/agent.md)、[安全边界](architecture/safety.md) |
| 排查终端、SSH 与输入 | [终端与工作区](architecture/terminal-workspace.md) |
| 理解知识库与追溯 | [知识与日志](architecture/knowledge-observability.md) |
| 开始开发和验证 | [环境](development/setup.md)、[测试检查](development/testing.md) |
| 与其它人或 AI 协作 | [贡献指南](../CONTRIBUTING.md)、[三人固定流程](development/team-workflow.md)、[AI 协作](development/ai-collaboration.md) |
| 随代码提交更新说明 | [更新目录与模板](updates/README.md) |
| 查当前设计方向 | [方案目录](plans/README.md)、[重要决策](decisions/README.md) |
| 管理文档与交接 | [文档和目录规范](development/documentation.md) |
| 准备比赛 | [比赛总目录](../competitions/README.md) |
| 查研究与每周情报的使用规则 | [研究目录](research/README.md) |

本机 AI 的分支、未提交候选、证据和待批准操作在 `.ai/CURRENT.md`；这些不应复制成公开的运行日志。新克隆没有本地工作记录是正常的。

旧版 Wiki、总账和专题报告已按用途归档；它们保留原日期与来源，不能重新当成当前能力声明。
