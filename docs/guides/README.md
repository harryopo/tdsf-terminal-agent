# 使用与问题反馈

安装与配置先看 [项目主页](../../README.md)。使用前确认目标是本地、WSL 还是 SSH，以及 Agent 当前指向哪个终端。

- 文件浏览的认证身份与 shell 内 `su` 后的用户可能不同；恢复目录跟随不等于切换 SFTP 身份。
- 命令建议与生成内容需要检查，插入不等于执行。自动提示不能替代审批和真实回显。
- 知识库里的内置、私人整理和原始参考保留各自来源，导入前避免覆盖现有内容。
- 工具执行细节和对话追溯集中看置信度浮窗；导出前检查包含内容与脱敏范围。
- 反馈问题请注明软件/候选版本、环境、操作顺序和实际结果；截图遮住密钥与私人信息。

已知范围与未验收部分见 [项目状态](../STATUS.md)，不要用旧安装包证明新工作树的修复已经生效。
