# Agent 四档信任模式说明

> 入口：AI 面板输入区上方的模式切换器（观察 / 确认 / 自动 / 教学）。

## 四档的区别

| 档位 | 权限 | AI 行为 | 适用场景 |
|------|------|---------|---------|
| **观察**（只读） | 只能使用只读工具（读文件/查日志/看进程/网络诊断/知识检索），schema 里**根本没有**执行类工具 | 只分析和讲解，任何写操作直接拒绝 | 想先了解情况、怕 AI 乱动服务器 |
| **确认**（默认） | 全部工具可用；写操作（L2+）逐条弹审批卡 | 每个写操作先展示「命令预览 + 用途解释 + 影响预测」，等你批准 | 日常教学主力档：每一步都在你眼皮底下 |
| **自动** | L0-L2 低危自动放行；L3（如 service 重启）升级确认；L4（rm -rf 级）**永远确认** | 高效执行 + 事后报告 | 已信任 AI 做常规操作，不想频繁点批准 |
| **教学** | 只读（同观察档） | 额外注入教学输出契约：回答按「概念 → 示例 → 易错点 → 练习」结构化展开（TeachCard 卡片渲染） | 跟着 AI 学知识点，要的是讲解不是动手 |

**一句话记住区别**：观察=只能看；确认=动手前每步问你；自动=小活自己干大活再问你；教学=只能看+讲得像老师。

## 审批卡（确认/自动档遇到写操作时）

自上而下四层信息：

1. **动作语义**：AI 想做什么（如"想重启 nginx 服务"）
2. **命令原文**：完整命令，永不改写
3. **用途解释**：AI 一句话解释这条命令的后果
4. **影响预测**：影响类别 + 对象 + 风险色带（绿 L0-L1 / 黄 L2 / 橙 L3 / 红 L4），由本地规则引擎解析，解析不了会明确标"影响未知——请人工审查"

三个按钮：

- **拒绝**：可附言（如"太危险，用 reload"），AI 会收到你的反馈并换方案
- **⚡批准且本会话只读免审**：本次执行 + 本会话内后续只读命令不再打断（不落盘，重开会话恢复谨慎）
- **执行**：只执行本次

## 安全底线（任何模式/白名单都不可绕）

- 内置黑名单：`rm -rf`（根/家目录）、`mkfs`、`dd` 写块设备、`shutdown`、`reboot`、`git push --force` 等永远需要人工确认
- 含危险构造（`$()`、反引号、`eval`、重定向系统文件）的命令永不自动放行
- AI 被拦截时必须如实报告"未执行"，禁止编造执行结果

详细规则见 [agent-审批白名单.md](agent-审批白名单.md)。
