# 可视执行演示（打字机）说明

> 入口：设置 → 智能体 → 可视执行演示（打字模式 + 演示速度）。AI 面板不再放快捷开关，保持界面简洁。

## 是什么

确认/自动模式下 AI 获批执行的命令，可以选择在终端里**逐字敲入**（模拟真人打字节奏），而不是整段瞬间出现——方便观察 AI 是怎么一步一步操作的，适合教学演示。

- **打字模式**：`整段注入`（默认，瞬时完成，适合专家/低延迟场景）/ `逐字演示`
- **演示速度**：0.2× ~ 5.0×（1.0× 下约 80 字符命令 14~22 秒）
- 超长命令（>200 字符）自动建议整段，避免等待过久

## 工作原理（详细注释）

逐字注入发生在 **Rust 写入端**（`src-tauri/src/modules/human_type.rs`），前端零改动：

- 采用经典 expect 工具的 `send_human` 算法：字符间隔 `t = alpha·(-ln U)^(1/shape)`（Weibull 分布逆变换采样），**词尾停顿更大**（alpha_eow），带 min/max 截断，首字符零延迟——所以节奏是自然随机的，不是机械匀速
- 逐字符写入 PTY / SSH channel，**远端 shell 的回显就是真实击打效果**——你看到的每个字符都是服务器真实 echo 回来的
- 演示期间终端顶部会显示"Agent 正在演示输入"状态条

## 注意事项（8 条）

1. 打字前会自动清行（Ctrl-C）并等待提示符就绪
2. 只发送可打印字符 + 回车；制表符、粘贴模式序列会被剥离
3. 随机延迟由算法保证，不提供匀速选项（匀速观感"完全不自然"）
4. 命令含 `!` 时会告警（bash 历史展开有风险）
5. **含 `sudo` 的命令自动降级为整段注入**——密码输入不回显，打字机视觉无效，会提示你手动输密码
6. **演示中敲击任意键即可接管终端**（AI 立即停手）
7. 整段模式在 SSH 弱网下由 russh 流控窗口自动背压，无需担心
8. 逐字模式的等待时间 = 各字符延迟之和，赶时间请调高倍率或用整段

## 与三模式的关系

- 只有**确认/自动档获批的命令**会走可视执行；观察/教学档只读不执行
- 未连接 SSH / 本地终端同样支持（PTY 与 SSH channel 双端实现）
