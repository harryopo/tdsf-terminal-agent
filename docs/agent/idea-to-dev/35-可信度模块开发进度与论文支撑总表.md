**核心公式**（Guo 2017 §3.2）：
```
z = logit(conf) = log(conf / (1 - conf))
z' = z / T
conf_T = sigmoid(z') = 1 / (1 + exp(-z/T))

T = 1：    无校准（保持原值）
T < 1：    锐化（conf → 0/1，变得更"自信"）
T > 1：    平滑（conf → 0.5，变得更"谦逊"）
```

**ECE 桶式公式**（Guo 2017 §2 + Naeini 2015）：
```
ECE = Σ_m (|B_m| / n) × |acc(B_m) - conf(B_m)|

其中 B_m 是第 m 个分桶：
- 默认 10 个等宽桶
- 桶索引 = floor(conf × numBuckets)
- 桶内 acc = Σ(wasCorrect) / |B_m|
- 桶内 conf = Σ(reportedConfidence) / |B_m|
```

**多 Provider 隔离**（v1.2 新增）：
- 每个 Provider 独立维护 samples[] 与 optimalT
- 避免 DeepSeek（过度自信 T=3.5）与 Claude（保守 T=0.7）的 T 值相互污染
