## 三、v8.0 四大开发板块

### 板块 A：系统架构感知（System Profiler）

**优先级**：🔴 P0（核心需求）
**周期**：1-2 天
**目标**：登录后一键采集系统全量信息 → 生成 md 报告 → 弹窗预览 + 导出 md/pdf

#### A.1 用户故事

> 运维工程师在 openEuler 服务器上做架构盘点，需要快速输出一份"系统架构清单"。
> 传统方式：手动跑 27 个命令、抄写到 Word、整理排版，至少 30 分钟。
> TDSF 方式：点击「感知系统」按钮 → 1 秒后弹出精美 md 报告 → 可直接编辑 → 导出 md/pdf → 提交。

#### A.2 功能设计

```
连接服务器 → 检测到首次连接 → 弹窗提示「是否感知当前系统架构？」
                ↓ 用户确认
        system-profiler 模块触发
                ↓
        并发执行 27 个探查命令（5 秒内完成）
                ↓
        生成结构化 ProfilerResult 对象
                ↓
        模板引擎渲染为 md 文本
                ↓
        MarkdownPreview 弹窗展示
                ↓
        用户可编辑 / 导出（md / pdf / html）
```

| 网络 | 4 | ip addr, ip route, resolv.conf, ss -tlnp |
| 用户 | 3 | whoami, /etc/passwd, sudo 权限 |
| 服务 | 2 | running services, enabled services |
| 开发工具 | 25+ | python/node/java/docker/mysql... 自动检测 |
| 虚拟化 | 2 | systemd-detect-virt, /proc/1/cgroup |
| Web 应用 | 1 | /var/www, nginx/apache 配置目录 |
| 运维 | 2 | crontab, /var/log 列表 |
