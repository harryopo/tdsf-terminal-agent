## 一、产品定位与差异化

### 1.1 一句话定位

**TDSF-Linux Desktop** = FinalShell 的 SSH 能力 + AI 运维助手 + 可信决策内核

### 1.2 与竞品的差异化矩阵

| 维度     | 焰龙AI      | ITOps Agent Platform | FinalShell | **TDSF-Linux Desktop（我们）**      |
| ------ | --------- | -------------------- | ---------- | ------------------------------- |
| 形态     | Web平台     | Web平台                | 桌面软件       | **桌面软件**                        |
| AI协作模式 | 自动闭环（人退出） | 多Agent自动执行           | 无AI        | **AI辅助决策+人工执行**                 |
| 可信度机制  | 无         | 无                    | 无          | **证据置信度公式+Ground-Check溯源**      |
| 风险控制   | 命令验证      | 命令安全可配               | 无          | **4层风险控制（语法→风险→人确认→审计）**        |
| 部署方式   | Docker部署  | Docker部署             | 安装即用       | **安装即用，零部署**                    |
| 数据安全   | 服务端存储     | 服务端存储                | 本地明文       | **本地加密，SSH密钥不走云端**              |
| LLM接入  | 内置固定      | 内置固定                 | 无          | **用户自配API Key，支持任意OpenAI兼容API** |
| 规模     | 500+场景    | 9个Agent              | 纯SSH       | **做精3-5个核心场景**                  |

### 1.3 核心特色（不做大，做细做精）

1. **证据可核验**：每条AI建议都附带日志证据溯源链，用户可点击验证
2. **风险可感知**：4层风险控制，高危操作必须人工确认，拒绝rm -rf /
3. **经验可沉淀**：历史决策卡片复用，成功案例自动积累为知识库
4. **本地化安全**：SSH密钥存储在系统钥匙串，API Key本地加密，不走云端
5. **LLM自由接入**：用户自配API Key/Base URL/模型名，支持火山方舟/OpenAI/任意兼容API

## 二、技术架构

### 2.1 技术栈

| 层级        | 技术选型             | 理由                                                 |
| --------- | ---------------- | -------------------------------------------------- |
| **GUI框架** | PySide6 6.7+     | Python原生Qt绑定，性能好，组件丰富，与现有Python代码兼容                |
| **SSH库**  | paramiko 3.4+    | 成熟稳定的Python SSH库，cube-shell验证可行                    |
| **终端模拟**  | pyte 0.8+        | Linux终端数据流解析，配合Qt渲染                                |
| **LLM接入** | openai SDK       | OpenAI兼容协议，支持火山方舟/任意兼容API                          |
| **核心算法**  | 复用tdsf-linux核心模块 | confidence/grounding/risk\_engine/decision\_engine |
| **数据存储**  | SQLite + 本地加密    | 决策历史+审计日志，密钥走系统钥匙串                                 |
| **打包**    | Nuitka           | Python→原生二进制，性能提升50%，体积减小40%                       |

## 三、核心功能模块（MVP）

### 3.1 SSH终端 + SFTP文件管理

**功能**：

* 服务器列表管理（分组、搜索、快速连接）

* SSH终端（多标签、命令高亮、复制粘贴）

* SFTP文件管理（上传/下载/编辑/权限修改）

**技术实现**：

* paramiko建立SSH连接，Transport + Channel

* pyte解析终端数据流，QTextEdit渲染

* SFTPClient实现文件操作

### 3.2 AI对话 + 日志分析

**功能**：

* 侧边栏AI对话窗口

* 粘贴日志 → AI分析根因 → 给出建议命令

* 证据链可视化（每条建议附带日志溯源）

* 决策卡片展示（置信度+风险等级+修复命令）

**技术实现**：

* 复用tdsf-linux的LLMClient调用大模型

* 复用confidence/grounding/risk\_engine/decision\_engine

* AI建议必须经过4层风险控制

* 高危操作弹出确认对话框

### 3.3 服务器监控面板

**功能**：

* 实时CPU/内存/磁盘/网络监控

* 异常告警（CPU>80%、磁盘>90%等）

* 历史趋势图表

**技术实现**：

* SSH执行`top`/`free`/`df`/`vnstat`等命令采集指标

* QTimer定时轮询（默认5秒）

* QtCharts绘制实时图表

### 3.4 AI配置卡片（接入自己的大模型）

**功能**：

* 设置页面输入API Key/Base URL/模型名

* 支持火山方舟/OpenAI/任意OpenAI兼容API

* 连接测试按钮

* API Key加密存储（系统钥匙串）

**技术实现**：

* keyring库存储API Key到系统钥匙串

* 配置保存到SQLite或JSON

* 测试连接调用`client.models.list()`

## 六、与竞品的核心差异总结

### 6.1 vs FinalShell

* FinalShell：纯SSH工具，无AI

* **我们**：SSH + AI运维助手，证据可溯源

### 6.2 vs 焰龙AI

* 焰龙AI：自动闭环，人退出执行环

* **我们**：人机协同，AI辅助决策+人工执行，更安全

### 6.3 vs ITOps Agent Platform

* ITOps：Web平台，需Docker部署，多Agent

* **我们**：桌面软件，安装即用，单Agent精简

### 6.4 vs cube-shell

* cube-shell：Python+PySide6+paramiko，有openai但无可信度机制

* **我们**：相同技术栈，但增加Ground-Check+置信度+4层风险控制
