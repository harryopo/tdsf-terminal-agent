## 六、明确不采纳清单

| 技术 | 原因 |
|------|------|
| Docker 主程序部署 | 桌面软件路线已定，五杀优势 |
| 复制 databuff 代码 | AGPL-3.0 强 Copyleft |
| LangGraph.js | Vercel AI SDK 7 更轻量 |
| LlamaIndex.TS | 2026-03 已废弃 |
| keytar | safeStorage 是 Electron 30+ 推荐 |
| 知识图谱/因果超图 | 3 周无法可信复现 |
| Granger 因果检验 | 单次故障样本太少 |
| 自动化自愈执行 | 与"人机协同"定位冲突 |
| 多智能体并发协同 | 技术栈过重 |
