## 3. 关键决策（v1.5 一周冲刺）

| 决策 | 内容 | 依据 |
|------|------|------|
| **DEC-1** | Sidecar-B/C 共享 Sidecar-A 的 venv | v1.5 简化开发，独立 venv 增加 5-10 倍部署时间 |
| **DEC-2** | OpenDerisk 双阶段诊断（规则 + LLM + fallback） | 纯规则太弱，纯 LLM 太重；混合方案 + fallback 保证可靠 |
| **DEC-3** | LLM 配置支持请求级和环境级 | UI 可配置，代码也可调（测试用） |
| **DEC-4** | 端口 19000/19001/19002（避开 7931-8080 系统保留段） | Windows 上 7931-8080 被服务占用 |
| **DEC-5** | SidecarManager 单例按 id 缓存 | 多次启动相同 sidecar 复用 manager |
| **DEC-6** | 健康检查间隔 5s，启动超时 10s | 平衡响应速度和误报 |
| **DEC-7** | RRF k=60（Cormack 2009 经验值） | 论文证明 k=60 在多种任务上最优 |
| **DEC-8** | FTS5 查询双引号包裹 | 防止用户输入解释为 FTS5 语法 |
