# Agent 原生桌面验收计划（2026-09-06）

## 目标

将已通过代码回归的 Agent 改动收敛为可观察的原生桌面验收；不以模型叙述或 UI 文案替代真实工具事件。

## 验收顺序

1. **执行模式**：确认模式让只读感知命令直接运行，写入命令每个会话仅展示 FIFO 队首的一条审批；自动模式执行普通命令，但真实 `reboot`/`shutdown` 不得发送。
2. **WSL 与本地工作区**：在指定发行版执行 `pwd` 与 Python 探测，确认没有 Windows 进程访问 Linux cwd；从 WSL 新建本地工作区后，路径和终端回到 Windows 本地上下文。
3. **教学与知识库**：普通 `knowledge_search` 仅显示为可折叠检索证据；仅 `tdsf:teach` 触发 TeachCard；保存命中、空结果、失败三种真实工具事件。
4. **SSH 参数补全**：在已保存 SSH profile 上确认入口；仅在用户点击后重试可选 `carapace` 安装，保存成功版本或精确失败阶段。该功能不是 Git 下载，也不影响 Git、SSH 或 Agent 核心执行。

## 证据与修复规则

每一项只在保存输入、工具事件、sidecar 日志和 operation ID 后判定通过。发现问题时，先保留可复现输入并增加最小回归测试，再做最小修复；验收未完成前不得宣称端到端完成。
