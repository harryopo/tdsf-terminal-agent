## 1. 关闭的三项阻断

### C1 在飞请求失效

- `closeNextCommand()`、`handleLeafInvalidated()`、终端输入变化都会推进请求代次；任何 `await` 返回后
  写状态前统一复核“代次 + 真实 scope（环境 / SSH 连接代次 / leaf 代次）”。
- 词表拉取、风险计算、自动纠错定时器、leaf detach / 重建全部覆盖；迟到结果不能重开面板或覆盖新面板。

### C2 输入行三态与原子回填

- `getCompletionLineSnapshot()` 明确返回 `known-empty` / `known-text` / `unknown`，并带输入版本。
- 光标移动、`Delete`、粘贴、Ctrl/Alt/Meta 编辑键、IME/多字节输入、`term.onData` 控制序列都使输入行转为
  `unknown`；`Enter` / `Ctrl+C` 恢复 `known-empty`。
- `writeCompletionLine()` 在同一同步调用内复核状态、原文、版本并写入；unknown 一律拒绝，不猜清行、不发 Ctrl+C。
- 失败命令（block）纠错与下一步建议都只允许在“可证明的空提示符”上回填；当前行纠错要求 `known-text` 且原文/版本一致。

### C3 命令捕获完整性与退出码归属

- Bash（本地 rcfile 与 SSH 注入）与 Zsh 在 `133;D` 前上报新私有标记
  `633;F;<segments>;<valid>;<nonce>`；第一份为准，nonce 必须与 `633;E` 一致。
- `valid` 只用 history 作为**证据**（号 = `HISTCMD`、较上一行推进、去行首空白后等于 `$BASH_COMMAND`）；
  命令文本始终取 `$BASH_COMMAND`，没有回退 `history 1`，也没有用渲染文本拼原文。
- `TerminalBlock.commandComplete`：`true` 才允许 127 失败纠错；`false` 不参与学习/不造转移；`undefined`
  （旧 shell、fish 等）保守不弹纠错，保留既有成功学习行为。
- 用户已占用 DEBUG trap 时保持降级，不上报 E/F，不伪造命令。

## 2. 交互与作用域

- 面板跟随真实 leaf：跨 leaf 按键、槽位解绑、终端销毁都会使旧面板/旧请求失效。
- WSL 命令集迟到返回按 leaf 代次丢弃，不写进复用的 leafId。
- L2 纠错候选允许“只回填、不执行”；L3/L4 仍隐藏；普通下一步建议仍只接受 L0/L1。
- 保持紧凑默认一条、`↓` 首次展开、黑白灰视觉与“Enter / → 回填、仅回填不执行”。
- 弹窗按钮不再抢终端焦点（`onMouseDown` 阻止默认聚焦）。
