日期：2026-11-13。状态：审查候选已提交至[草稿 PR #49](https://github.com/harryopo/tdsf-terminal-agent/pull/49)，远端 main 尚未更新。候选完整 SHA 和检查结果以 PR 当前提交为准，成员正式启动基线仍待队长公布。用途是三人开发与代码审查，不是安装包发布或稳定性保证。

## 本次纳入

- 已有开发主线的产品源码与远端主线的同步内容，绑定候选提交查看，不从队长的未提交目录推断。
- 共享风险 RPC 的只读边界修复及回归，保留相对 sidecar 包的配置加载和简单查询规则。含 shell 控制、展开、重定向等语法时，前缀规则不足以证明只读，退回确认；引号内的这些字符也保守处理，不声称完整解析 shell。
- [入门路线](team-onboarding.md)、[固定流程](team-workflow.md)、两名成员的审查任务和精选公开文档。
- SSH 安全依赖窄升级、中文路径字节编码修复与跨平台检查，见[对应更新说明](../updates/2026-11-13-shared-security-SSH依赖与回执兼容.md)；不把旧提交的检查结果用于证明新提交。
- 预测算法/上下文库、候选展示源文件与离线回放材料，供独立检查和后续开发；这些模块本身的已知边界仍待修，不因保留源文件就称已上线。

## 继续留在候选，暂不接入运行入口

尚未验收的下一命令/自动纠错挂载、终端输入写入接线、快捷键拦截和 SSH 生命周期改动留在队长原工作区；共同版本不导入这批新的生产接线。旧有命令补全与 SSH 功能仍沿既有实现，不新增开关或改为另一运行时。

库级回放和单测不替代真实输入、接受时重验目标、过期结果、开始/结束归属或原生验收。正式 F0（输入/建议/归属合同）尚未签发，依赖它的存储、展示整理和模型任务仍按原前置执行。保留内容在新任务中继续修，不删除或覆盖其他 AI 的成果。

## 如何开始

先阅读文档；队长公布可获取的共同提交后，再从该 SHA 创建自己的任务分支。每个 PR 记录起始基线、最近同步 main 和实际 HEAD。源码、自动测试、真实 SSH/桌面与安装验证分别报告，发现安全问题按 [安全政策](../../SECURITY.md)私下提交。

候选检查与最终合并分开：ROOT 准备与验证，队长审查具体差异后决定合并；不会由 CI 绿色、阅读包或这份说明自动更新 main。
