## 1. 项目概述

### 1.1 项目名称

**TDSF Terminal Agent**（产品标识：`com.tdsf.terminal-agent`）

### 1.2 项目定位

TDSF Terminal Agent 是一款**终端优先的 Linux 运维 AI 工作台桌面应用**，专为 Linux 运维教学场景设计。

它将终端操作、远程服务器管理、AI 智能辅助、知识库检索四大能力深度融合，为运维学习者提供"一站式"的实践与学习环境。

### 1.3 解决什么问题

| 痛点 | TDSF 解决方案 |
|------|--------------|
| Linux 运维学习门槛高，命令繁多，新手无所适从 | AI Agent 实时辅助，知识库即时检索，教学 Agent 系统讲解 |
| 本地终端与远程服务器管理工具割裂 | 内置 SSH 资源管理器 + 远程文件管理，本地/远程无缝切换 |
| 运维知识碎片化，难以积累和复用 | 离线知识库（向量 + FTS5 双路检索）+ 历史案例系统 |
| 传统 AI 助手无法直接操作终端，只能"纸上谈兵" | AI Agent 可通过 Rust 后端执行终端命令（PTY/SSH），MCP 工具提供风险评估、知识检索、决策引擎等辅助能力，"能说能做" |
| 运维操作缺乏安全审计，误操作风险高 | AI 工具审批机制 + 风险评估 + SSRF 防护，安全可控 |

## 2. 项目背景与动机

### 2.1 Linux 运维教学痛点

Linux 运维是计算机科学教育中的核心技能，但教学过程中存在以下突出问题：

1. **命令复杂度高**：Linux 系统管理涉及数百条命令和配置文件，学生记忆负担重，容易遗忘。
2. **实践环境搭建困难**：学生需要同时配置本地终端、SSH 连接、编辑器、文档等多个工具，环境碎片化严重。
3. **知识获取低效**：遇到问题时需要切换浏览器搜索、翻阅文档，打断操作流程，学习效率低。
4. **缺乏即时指导**：传统教学中，学生遇到问题需等待教师答疑，无法获得实时帮助。
5. **安全意识薄弱**：新手在操作生产环境时，容易执行危险命令（如 `rm -rf /`），缺乏安全审计机制。

### 2.2 项目动机

基于上述痛点，我们开发了 TDSF Terminal Agent——一个将**终端操作、远程管理、AI 辅助、知识管理**深度集成的桌面工作台，让学生在统一环境中完成"学、练、查、管"全流程，显著降低 Linux 运维学习门槛。

## 3. 核心创新点

### 3.1 三进程分离架构

突破传统 Electron 应用的双层架构，创新性地采用 **Tauri 主进程（Rust）+ WebView 前端（React）+ Python Sidecar** 三进程架构：

- **Rust 主进程**：负责系统级操作（PTY、SSH、文件系统），保证性能与安全。
- **React 前端**：专注 UI 渲染与用户交互，独立演进。
- **Python Sidecar**：承载 AI 推理与知识检索，充分利用 Python 生态（LangGraph、LangChain、ChromaDB）。

三者通过 IPC + JSON-RPC 2.0 松耦合通信，各司其职，互不干扰。

### 3.2 PAOR 监督循环（Plan-Act-Observe-Reflect）

基于 LangGraph 构建的 7 节点状态图，实现 AI Agent 的自主决策与执行闭环：

```
supervisor → plan → act → tool_call → permission_check → observe → reflect → (循环/结束)
```

每一轮执行都经过"规划 → 执行 → 观察 → 反思"四个阶段，确保 AI 行为可控、可追溯。

### 3.3 9 个专职 Agent 协作

系统内置 9 个专职 Agent，覆盖运维教学的主要场景：

| Agent | 职责 |
|-------|------|
| `main` | 主 Agent，任务分发与协调 |
| `coding` | 代码编写与脚本开发 |
| `explore` | 系统探索与信息收集 |
| `history` | 历史案例检索与复用 |
| `teach` | 教学讲解与知识传授 |
| `debug` | 故障诊断与调试 |
| `refactor` | 代码重构与优化 |
| `test` | 测试执行与验证 |
| `deploy` | 部署操作与环境管理 |

### 3.4 离线知识库双路检索

采用 **ChromaDB 向量检索 + SQLite FTS5 关键词检索**双路并行方案，兼顾语义相似度和精确匹配，即使在无网络环境下也能快速检索运维知识。

### 3.5 终端渲染池

创新性的终端渲染池架构（最大 5 槽位 + DormantRing 回收机制），支持多终端实例高效复用，避免频繁创建/销毁 xterm.js 实例带来的性能开销。

### 3.6 安全审批机制

AI Agent 调用工具时，只读操作自动执行，变更操作需用户审批。结合 4 层风险评估管道（L0-L4），从源头拦截危险操作。

## 5. 核心功能展示

### 5.1 终端模拟器

- 基于 xterm.js 6 的高性能终端渲染，支持真彩色、Unicode、连字。
- 终端渲染池（5 槽位 + DormantRing），多终端实例高效复用。
- 支持本地 PTY 和 SSH 远程终端统一渲染。

### 5.2 SSH 远程管理

- 内置 SSH 客户端（基于 russh 0.61），支持密码、公钥两种认证方式。
- SSH 资源管理器：可视化管理远程主机，一键连接。
- 远程文件管理（基于 russh-sftp 2.1）：浏览、编辑、上传、下载远程文件。
- TOFU（Trust On First Use）主机密钥审批机制。

### 5.3 AI Agent 智能助手

- 9 个专职 Agent 协同工作，主 Agent 自动分发任务到合适的子 Agent。
- PAOR 监督循环确保 AI 行为可控、可追溯。
- 支持 Bring Your Own Agent（BYOA），用户可自定义 Agent。
- AI 工具调用审批机制，变更操作需用户确认。

### 5.4 知识库系统

- 离线知识库：ChromaDB 向量检索 + SQLite FTS5 关键词检索，双路并行。
- 支持文档导入、自动分块、语义索引。
- 历史案例系统：记录操作历史，支持多维检索与复用。

### 5.5 技能系统（Skills）

- 预置常用运维技能（如 Nginx 配置、Docker 管理、系统监控等）。
- 技能卡片式展示，一键执行。
- 支持自定义技能扩展。

### 5.6 主题与个性化

- 16 套精心设计的主题，涵盖亮色/暗色风格。
- 基于 CSS 变量的主题系统，支持自定义扩展。
- 终端配色与 UI 主题联动。

### 5.7 其他功能

- **Monaco 编辑器**：Trae 同源的代码编辑器，支持语法高亮、代码折叠。
- **源控制**：内置 Git 可视化操作（基于 git2 0.19）。
- **命令面板**：快速搜索和执行所有命令。
- **离线翻译**：支持终端输出的实时翻译。
- **LSP 支持**：语言服务器协议集成，提供代码智能提示。

| 技术 | 版本 | 选型理由 |
|------|------|---------|

## 8. 应用场景

### 8.1 Linux 运维教学

- 高校/培训机构的 Linux 运维课程实训环境。
- 学生在统一工作台中完成终端操作、服务器管理、故障排查。
- AI Agent 充当"虚拟助教"，实时解答学生疑问。

### 8.2 运维新手自学

- 个人学习 Linux 运维的一体化工具。
- 知识库提供即时参考，历史案例帮助积累经验。
- 技能系统引导新手完成常见运维任务。

### 8.3 运维团队日常管理

- 团队统一使用 TDSF 管理多台服务器。
- SSH 资源管理器集中管理主机列表。
- AI Agent 辅助日常运维操作，降低人为失误。

### 8.4 DevOps 实践

- 集成 Git、Docker、部署工具，支持 DevOps 教学。
- 源控制可视化 + 部署 Agent，覆盖 CI/CD 教学场景。

## 9. 总结

TDSF Terminal Agent 以**三进程分离架构**为基座，以**PAOR 监督循环**驱动 9 个专职 Agent，以**双路知识库**支撑离线检索，构建了一个安全、智能、高效的 Linux 运维教学工作台。

项目的核心价值在于：

1. **降低门槛**：将分散的运维工具整合为统一工作台，AI 辅助贯穿始终。
2. **安全可控**：Rust 系统层保证安全边界，AI 审批机制防止误操作。
3. **离线可用**：知识库本地化部署，无网络环境也能正常使用。
4. **可扩展**：BYOA（Bring Your Own Agent）+ 技能系统 + 插件规划，生态开放。

我们相信，TDSF Terminal Agent 能够为 Linux 运维教育带来全新的体验，让更多人高效、安全地掌握 Linux 运维技能。
