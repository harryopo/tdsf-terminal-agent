# 演示视频放置目录

把宣传 / 演示视频放到这里，README 与宣传页都会引用它。

## 怎么放

1. 把视频文件命名为 **`demo.mp4`**（H.264 + AAC，建议 1920×1080、30fps、≤ 60 秒、体积 ≤ 20 MB），放进本目录：
   ```
   assets/video/demo.mp4
   ```
2. 可选：放一张封面图 **`poster.png`**（16:9，建议 1920×1080），用于视频加载前的占位与 README 缩略图。

## 放在这里之后会自动出现在哪

| 位置 | 引用方式 | 说明 |
|------|---------|------|
| `README.md` | `assets/video/demo.mp4` / `poster.png` | GitHub 的 markdown 会过滤 `<video>` 标签，README 里用**封面图 + 链接**的方式呈现；如需直接站内播放，把视频拖进 GitHub Release 或 Issue 拿到 CDN 链接后替换 README 中的链接即可 |
| `website/index.html` | `../assets/video/demo.mp4` | 宣传页原生 `<video>` 播放（本地/整仓部署时生效） |

## 部署宣传页时注意

若只把 `website/` 目录单独部署（而不是整仓根目录），请把 `demo.mp4` 与 `poster.png` 一并复制到 `website/assets/video/`，页面会自动优先使用同目录文件。

## 内容建议（30–60 秒）

1. 新建 SSH 工作区 → 连接服务器
2. 对 Agent 说一句排障/部署需求 → 观察它**逐字敲进真实终端**（蓝色回显）
3. 审批卡出现 → 确认执行 → 终端真实输出回流到工具卡
4. 切到教学模式 → 单步命令卡 → 学生点击执行 → 结果回填后继续讲解
5. 资源管理器跟随 cwd、拖拽上传一个文件

> 录制前请隐藏真实 IP、账号、绝对路径与密钥。
