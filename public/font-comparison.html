🎨 TDSF Terminal Agent — 终端字体对比（修复前 vs 修复后）

用户反馈"终端文字特别丑"，根因：fonts.ts 的字体 fallback 链全是 macOS/Linux 字体（JetBrains Mono / Menlo / SFMono），Windows 上没装，最终回退到 web 默认 → Times Roman 等衬线字体。

修复：增加平台检测，Windows 强制使用 Cascadia Code / Consolas（系统自带等宽字体）。

❌ 修复前（fonts.ts 旧版）

FALLBACK_CHAIN（旧）
rm -rf /tmp/test PS C:\Users\Lenovo> ls -la TIMES ROMAN FALLBACK

✅ 修复后（fonts.ts 新版，平台检测）

Windows fallback
rm -rf /tmp/test PS C:\Users\Lenovo> ls -la CASCADIA CODE
macOS fallback
rm -rf /tmp/test PS C:\Users\Lenovo> ls -la MENLO
Linux fallback
rm -rf /tmp/test PS C:\Users\Lenovo> ls -la DEJAVU
Nerd Font（可选）
rm -rf /tmp/test PS C:\Users\Lenovo> ls -la NERD

🖥️ 终端实际渲染对比

修复前（Times Roman 渲染）

PS C:\Users\Lenovo> rm -rf /tmp/test
rm: cannot remove '/tmp/test': No such file or directory
PS C:\Users\Lenovo> ls -la
total 0 drw-r--r-- Lenovo Users 0 Jul 27 13:00 .

修复后（Cascadia Code 渲染）

PS C:\Users\Lenovo> rm -rf /tmp/test
rm: cannot remove '/tmp/test': No such file or directory
PS C:\Users\Lenovo> ls -la
total 0 drw-r--r-- Lenovo Users 0 Jul 27 13:00 .

⚠️ 浏览器会先尝试解析首个字体名（JetBrains Mono / Cascadia Code）。系统存在则用之，不存在则按顺序 fallback。本机 Windows 11 没装 Nerd Font 家族，所以走 Cascadia Code / Consolas 这条链；这两者都是 Windows 11 系统预装的等宽字体（PowerShell 终端默认就是 Cascadia Code），渲染清晰锐利。

✅ 视觉效果：TDSF 终端现在用与 Windows Terminal / PowerShell 一致的字体，吊打 macOS-only 字体链。
