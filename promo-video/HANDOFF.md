# 宣传片交接说明（2026-09-10）

## 制作结论

该宣传片改由其他 AI/剪辑工具继续制作。本目录保留的是已经确定的内容与真实素材准备状态，不能将它误认为已完成的 Remotion 工程或成片。

唯一有效分镜、字幕和声音约束在 [production-spec.md](docs/production-spec.md)：

- 16:9、1920×1080、30fps、约 100–112 秒。
- **最终只交付带 BGM 的版本**；不再另做无 BGM 版本。
- 既有软件功能只能使用真实桌面录屏或真实截图；不可手搓、仿造或替代 TDSF UI。
- 采集前必须隐藏 IP、账号、绝对路径、密钥和其他个人信息。

## 已有素材

`assets/` 保存五张真实桌面截图；`public/` 是为后续剪辑临时复制的同一批截图与 BGM/SFX。后续制作择一目录整理即可，避免重复入片：

- SSH 工具卡回显
- 远程资源树与文件编辑
- 可见终端与 Agent
- 教学模式
- 模型/上下文浮层

## 软件事实（供镜头脚本使用）

- Agent 可选后台 SSH 通道或可见终端 Shell；可见模式的 Agent 命令现由 xterm 在**真实回显层**标为蓝色。命令字节、远端执行与原生输出不变。
- SSH 长命令实时 stdout/stderr 只在对应 SSH 工具卡内折叠展开，不再单独占用前端输出面板。
- 教学模式按“一次一张命令卡 → 学生在当前可见终端执行 → 回显后继续”的节奏工作。
- 远程资源树按当前 SSH session 与 cwd 跟随，支持远程文件编辑和拖拽上传。

## 当前限制

本执行环境的桌面自动化接口未暴露 TDSF 原生窗口，不能由本 Agent 操作或录屏。因此尚未采集缺失的动态镜头；这是能力边界，不是产品界面缺失。
