# TDSF Terminal Agent 宣传片制作规格

## 基本设定

- 成片：16:9、1920×1080、30fps、约 100 秒。
- 视觉：沿用软件的深色终端、JetBrains Mono、 AI 命令、绿色成功态与紫色教学态；镜头稳、文字可读，不使用手绘仿真 UI。
- 素材规则：既有功能页面一律使用真实桌面录屏或真实截图。任何 IP、账号、绝对路径、密钥和个人信息在采集前脱敏。
- 声音：画面锁定后加入鼓点电子底、键盘、whoosh、点击与收尾 impact；最终只交付带 BGM 版本。

## 最终字幕

1. Linux 运维，不该止于试探与经验。
2. 这，是专为 Linux 运维打造的 AI 原生终端。
3. 它先感知现场环境，再完成规划、执行、校验的完整闭环。
4. 每条指令清晰可见，每步回显全程可溯。
5. 常规操作自主执行，高危指令二次确认。
6. 从文件管理、服务巡检到网络诊断，Agent 在真实环境中全域协同。
7. 它不止代你处理繁复操作，更帮你厘清每一步逻辑。
8. TDSF Terminal Agent：终端优先的 Linux 运维工作台。
